# 04 活动——实现方案

> 对应文档：doc/design/04-活动.md（初稿）
> 状态：初稿

## 1. 目标

把活动从事件挂载中解耦：

- 活动建立和完成记账保持；
- 移除 `activity_events_attached`；
- 移除 `_attach_focused_events`；
- 活动不再使用 `focused_event_ids`；
- 内部活动不再挂载活动段/事件。

## 2. 接口落点

- `src/jshi/subject/process.py`
- `src/jshi/subject/domain.py`（保持字段兼容）

## 3. 测试计划

- 更新 `tests/test_activity_lifecycle.py`；
- 删除事件挂载相关断言；
- 确认活动建立、完成、状态迁移仍通过。
