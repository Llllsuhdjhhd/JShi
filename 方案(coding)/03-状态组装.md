# 03 状态组装——实现方案

> 对应文档：doc/design/03-状态组装.md（初稿）
> 状态：初稿

## 1. 目标与范围

把 03 调整为消费 02 的原始活动窗口：

- `EventSource` 改为 `ActivityWindowSource`；
- `AssembledWorkingSet.active_segment_ids` 表示活动段 id；
- `SubjectState.concerns` 暂不来自活跃区；
- `current_state_assembled` 记录活动段 id；
- 更新测试中的 `ActiveZoneView` 构造。

不做：

- 事件本体独立；
- 03 内实现事件逻辑；
- 07/09 接回事件状态。

## 2. 接口落点

- `src/jshi/assembly/sources.py`；
- `src/jshi/assembly/assembler.py`；
- `src/jshi/assembly/port.py`；
- `src/jshi/subject/process.py`；
- `tests/test_assembly.py`。

## 3. 测试计划

- 活动窗口片段存在；
- 装载报告包含 `activity` 源；
- 无 `event` 源；
- `ActiveZoneView` 使用 `segments / start_sequence / budget_chars`；
- 既有预算、记忆源、失败隔离测试保持通过。

## 4. 风险

- 旧测试中事件断言需要迁移；
- 记忆源与活动窗口会同时出现，去重策略要避免把活动段当记忆；
- `concerns` 暂时为空，后续由 07/09 接回。
