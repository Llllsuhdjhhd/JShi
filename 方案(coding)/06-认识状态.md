# 06 认识状态——实现方案

> 对应文档：doc/design/06-认识状态.md（初稿）
> 状态：初稿

## 1. 目标

把认识状态迁移接入 ActivityLedger：

- 每次合法迁移后追加 `subject_state`；
- `state_delta` 包含 cognitive_content_id、from、to、reason；
- 来源链包含 transition.id 与迁移 source_ids。

## 2. 接口落点

- `src/jshi/subject/process.py`：`transition_cognition`。

## 3. 测试计划

- 迁移成功后 ActivityLedger 有 subject_state；
- 非法迁移不产生 subject_state；
- 状态段可进入后续活跃区窗口与记忆批次。
