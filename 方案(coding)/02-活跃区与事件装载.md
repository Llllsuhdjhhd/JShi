# 02 活跃区与活动窗口——实现方案

> 对应文档：doc/design/02-活跃区与事件装载.md（初稿）
> 状态：初稿

## 1. 目标与范围

把 02 改为原始活动窗口：

- `InProcessActiveZone` 依赖 `ActivityLedgerPort`；
- `load` 返回 `ActiveZoneView(segments, start_sequence, budget_chars)`；
- 不再提供 `evict_overflow` / `recall_by_ids`；
- `SubjectProcess` 阶段② 记录 `context_window_loaded`；
- 阶段⑦ 推进活跃区游标，不做事件剔除；
- `EventSource` 改为 `ActivityWindowSource`。

不做：

- 事件识别、未完成事件、事件边界；
- 事件剔除与召回；
- 活跃区事件持久化。

## 2. 接口落点

## 4. 测试计划

更新 `tests/test_active_zone.py`：

- 首次活动窗口包含当前外部输入；
- 第二次活动窗口不重复上一次活动；
- 窗口包含 reply 当它尚未推进时；
- 阶段② 记录 `context_window_loaded`；
- 活跃区不产生 `event_loaded` / `event_evicted`。
