## 3. 数据结构

**交接 `IntakeRecord`**

```text
intake_id
subject_id / object_id / activity_id
origin                 # external_05
need
verbal                 # 本轮口头，可空
field_ref              # {activity_id, zone_kind, zone_rev} 同现 hang
status                 # received | planned | failed | launched
plan_error             # 策划失败人话，可空
request_id / task_id   # 发出后才有
updated_at
```

无 `rewritten_context` 全文。

**记挂**仍用现 `HangRecord`，仅在 `launched` 之后创建。`list_visible` 合并：

- 策划失败：用 `intake_id`，摘要 = `plan_error`；
- 已跟随且规则可见（现 `notify_caller` 或等价）：用 `task_id`。

**05 JSON**

```text
use_tool: bool          # 可省略
need: str               # 与 use_tool 一起；过短则 200 策划失败
```

不要 template/params。`use_tool=false` 或两者皆空 = 不 intake。

**通用 estimate 占位（本刀）**

```text
benefit = need 截断
downside = "占位估价；内容由引擎执行"
time_est_ms / cost_est = 空
```

## 4. 行为变更

```text
回复调用 → 06 → 10 → 写场
         → 若 use_tool：200.intake(交接)（不等策划、不等执行）
         → 07 completed

200 后台：
  保存交接
  规则策划
  失败 → 交接 status=failed，list_visible 可见；无 hang
  成功 → 发出请求、建 hang、写 estimate、ToolRunner.start
```

- 本轮活动照关；10 不跑工具。
- 无 `use_tool`：不建交接、不建 hang（与现网「无 tool_request」相同）。
- 下一轮 03 可装到可见摘要；本刀仍不自动再开 05。
- Service 可重入：多次 `intake` 各开后台，不要全局一把锁堵住第二次。

`field_ref`：与现切片相同（写场后木头 `version`，人格 `activity_id`）。

## 5. 测试计划

工作区 `--basetemp`。改 `tests/test_tool_hang.py`，保留 `tests/test_tool_contract.py`。

- **指示**：认知 parse：`use_tool`+`need` 有；带 `template` 的旧键忽略；过短 need 仍可 parse，intake 后策划失败。
- **交接不是记挂**：`intake` 后立刻 `list_open` 为空；策划成功并 `drain` 后才有 hang。
- **策划失败**：need 过短 → 无 hang；`list_visible` 含失败摘要；活动 `completed`。
- **成功路径**：有口头 + `use_tool` → 活动 completed；口头仍走 10；`drain` 后三类反馈、`notify_caller`；`list_visible` 按对象过滤。
- **03**：`list_visible` 非空时工作集有 `source=tool` 片段；无则没有。
- **cancel**：发出后的 hang `cancel` 后不再可见。
- **回归**：`test_tool_contract.py`、`test_response_plan_flow.py`；无指示时 hang/交接空。

Pi 仍不进单测。策划器用规则，测试不打网。

## 6. 风险与未决

- **规则策划只会 echo**：对话里「要用」只会跑 Stub 回声，不是真检索。写明；205 真模型下一刀。
- **可见性仍是规则**：与设计「记挂可再评估」有差；本刀够 03 通路。
- **旧测试**大量构造 `tool_request=`，须一并改名。
- **tool.jsonl 与 hang.jsonl**：两文件更清晰；若嫌多，一个 jsonl + `kind`。本方案默认 **`tool.jsonl` 交接、`hang.jsonl` 跟随**。
- 来不来得及、Pi 流式：不在本刀。
