# 外部审计报告：独立复核与修复

日期：2026-10-29。核对基线：0860106。
来源：用户提供的桌面 JShi-audit-reports，含总报告及 01–09 分报告；采用其复核版结论，同时独立检查代码。

## 判断

报告有价值，复核时撤回了多项把设计契约当缺陷的判断。但严重程度与修法不能直接照搬：可选数字解析失败确实影响回复，尚无生产发生频率证据，不据此认定全面不可用；片场版本变化也不能直接等同输入依据失效。

| 意见 | 独立结论与处理 |
| --- | --- |
| 木头可选 recall_requests、importance_ranking 数字转换导致整轮失败 | 成立。按条隔离转换错误，跳过非法条目，保留回复及有效兄弟条目；拒绝非数组段与非有限重要性数值；引用字段只接收字符串数组。合法数字的默认值和限幅保持兼容。 |
| 人格流式回复依赖 reply/mode 顺序 | 成立。缓存完整 reply，收到明确 respond 后即可回调，同轮最多一次；没有 mode 或静默 mode 不提前播报。报告建议的“缺 mode 也默认 respond”不采纳。 |
| 短档工具输出限制只对 smith 生效 | 成立。程序按档位统一清除意外的工具意图、消费及处理声明，涵盖木头；完整档保留工具能力，不重复生成或替换已交付回复。 |
| 普通片场 commit 应提升 generation，或入口直接比较最新 version | 不采纳该修法。material_view 按输入截止时间选取片场，之后整理的事件会还原为当时未整理原话。material.version 可合法落后于 store.version；普通 commit 不改变这些原话的有效性。人工纠正及改写已有原话仍提升 generation。新增截止时间回归测试支持此判断，但不声称穷尽所有并发问题。 |
| stop 后重排应过滤旧批次 | 证据不足，不改。撞车判断用于及时阻止旧工作放行，旧话与新话仍需要入口联合确认停止、替换或独立操作。直接过滤可能丢失“停一下，改成……”所需的对象和内容。 |
| 短档人物保留、incomplete 等待、silent 操作、merge 重审 | 同意报告复核后的撤回结论，维持契约。 |
| 共用阈值、接续优先合批、needs/modules 遗留接口、人物预算和双协议维护 | 属于策略或工程债，未见必须改变现有行为的证据，本次不扩大改动。 |
| legacy reason/refs 校验及失败残留 hint | 主路径已有 serial 闸门，不能据兼容解析的局部差异直接改变三个现行模式；未将其认定为本次必须修复的问题。 |
| 流式用量、salvage 数组及组装报告细节 | 保留为观察项。流式接口只提供文本块，不能简单套用非流式响应的元数据保留函数；tool_consumed 契约是字符串数组，无需支持嵌套数组。 |

## 改动边界

本次修改输出解析、流式交付时机及工具能力约束，不修改模型提示词正文、system/user 组包、分支选择或输出 Schema，也不改变入口模式设置。

新增 tests/test_external_audit_hardening.py：覆盖坏数值与有效条目共存、错误段类型、两种字段顺序和四种回应模式及无有效模式、木头/斯密斯三个档位的工具权限，以及普通整理与原话纠正的片场时效差异。

验证：主认知、流式、档位、召回、片场、入口、撞车、主体和组装相关十个测试文件共 169 项通过；随后新增两项无有效模式的流式测试，本次专项 32 项全部通过。合计 171 个不同用例通过，未运行全仓测试。代码差异格式检查通过。
