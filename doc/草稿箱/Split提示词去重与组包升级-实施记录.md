# Split 提示词去重与组包升级

最近更新时间：2026-11-01 14:26（北京时间）。

目标：提高复杂环境下人物、交往对象及接话判断的准确性，减少主认知前的输入负担。沿用两阶段，不新增模式、模型调用或持续理解机制。

## 本次变更

- 输入说明合并重复的证据、时间与摘要边界。保留声音支持与身份概率的区别、暂归不升级、未知不补造、旧画面不刷新。
- 人物部分精简现场与连续性说明，保留有效现场可支持确认、候选唯一不能独立确认、新反证只修正受影响部分。
- 交往规则及点名、延迟问答、家庭辣度正反例保留。明确完整度是意思足够处理，不是语法完整或转写定稿；补充“七点”与“帮我把……”的说明性对照。
- 删除重复JSON输出示意；类型、枚举、必填和长度以实际Schema为准，保留程序不能仅靠Schema表达的逐句候选与跨字段约束。Schema未改。
- 回应准备的items仅包含process_refs或pending_refs关联的人物；原始entry不修改，待续人物仍保留。现场、新事件、控制理由和依据引用继续传递，避免误删接话反证。
- 不改ID映射、媒体关联、时间值、路由或控制执行；既有紧凑JSON与短引用继续使用。

## 影响与限制

共享提示词也用于combined及decision的对应聊天分支，已同步这些文档；不是新增模式。没有切换保存配置、重启服务或进行外部模型回放。

本轮确认了文本缩短和程序契约兼容，未证明真实模型准确率或墙钟延迟改善。误认人、误接话、漏接话、后续反证和真实耗时仍须用同版真实场景评估；未新增持久关系修正机制，不把提示词中的纠正要求当成程序已完成历史修复。
