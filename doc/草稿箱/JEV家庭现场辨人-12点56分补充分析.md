# 12:56 现场辨人的补充分析

这是独立于12:50—54运行质量复查的新问题。本轮只分析，没有修改运行程序。

用户现场确认：截图中低相似度时候选第一名仍是正确人物。由此可把这几句用于后续带真值测试，不能推广成低相似度第一名总是正确。

实际记录：12:56:47“不美好不简单。”声纹P2/luguang 0.339，被第一次JEV确认为P2；约3.13秒后“看小狗在飞。”luguang 0.153、lux 0.048、qf 0.027，声纹初判给新临时对象P22（待定声音3），第一次JEV仍沿用P22/可能。

后一句第一次JEV实际拿到了前一句P2原话及时间；随后合批再次JEV，两句也同时在输入内。不存在前一句完全丢失的问题。但截图两句均轨迹7，第一次JEV的精简输入未传track或同声音可靠关联材料，只呈现P2和P22两个对象代号。轨迹号本身来自分段，不等于可靠声纹连续性，不能简单拿同号就并人；可以补短的有来源的连续性信息，让模型区分有依据的同声音关联与纯轨迹号巧合。

片场主要仍在讲lux保养车、旧机制解释和旧任务，缺少这一段当前多人共同活动、各人最近确认发言的清楚关系。旧片场还写“未过阈值归属不定”，容易让模型把程序声纹门槛当作自己的最终判定门槛。

方向应当是：声纹原分数与领先提供声音线索，第二段整理现有成员、交往关系、最近确认和变化，第一段内部假设当前家庭等场景并综合确定程度，不再机械照抄程序声纹是否过门槛。场景缩小合理候选范围，不凭空排除新人或媒体声；不同来源证据可以共同支持最终确认。第一段可以在声纹低于程序门槛时，综合足够依据确认P2。没有校准数据时不要把0.153称为15.3%的身份概率，也不要把两段模型调用当两份独立声音证据。

建议下一次实现前先用这些用户已确认句子做真实请求回放：对比原材料、清理后的当前片场、补充可靠连续性线索，观察P2是否被提升及是否误并别的声音。先建立通用的证据组合与冲突处理，再调提示词，不为家庭场景写硬编码规则。本案例未运行该对比测试。
