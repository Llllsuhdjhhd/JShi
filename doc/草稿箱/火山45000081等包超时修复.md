# 火山45000081等包超时修复（2026-10-30）

官方含义：服务端8秒未收到下一音频包，主动断开。不是“8秒没人说话”；正常静音PCM也应持续传输。

发现的程序问题：WebSocket连接处理先open_stream，再加载Smart Turn、Silero及语义模型，然后发送ready让页面开始音频。冷启动可能超过上游8秒等包预算，导致尚未开始送音频即断开。

修复：先完成本地模型初始化，再建立上游识别连接，随后启动接收并发送ready。本地初始化失败沿用既有降级，再建立连接。未添加假静音保活、音频补帧或自动重放旧音频。

错误详情同时保留message、msg或error；45000081没有详情时显示8秒等包超时中文说明，保留原错误码。未知错误不套用这个解释。

只凭用户堆栈不能确定每次断开都是冷启动导致；页面采集暂停、网络中断或运行中的事件循环阻塞也可能造成相同错误。此轮修复了已确认存在的启动顺序风险，运行时断包需结合音频收包时刻继续定位。没有重启正在运行的服务，没有上传录音。

回归覆盖启动顺序、原有收发／关闭路径，以及服务端详情保留和空详情中文解释。

依据：[火山官方错误码](https://docs.volcengine.com/docs/doubao-voice/error-code-query?lang=zh)。
