# 模式三原生两阶段：实施记录

最近更新时间：2026-11-01 19:51（北京时间）。

## 已完成

现有decision正式宿主bridge采用native-v3。第一阶段每条人物、确定度、交往、完整度4题加本批控制/停后操作2题，动态候选最多3条14题；超限、图片/环境观察、材料范围不全等回退Split。人物unknown可为有效结果，不固定增加普通辨人调用。背景表达未完不阻塞。原始答案、分数、题目进入服务审计，程序组合说明不冒充模型理由。

第二阶段原生5题选择档位、记忆、带图、回应方式及可选接话；入口被采纳后第二阶段失败只回退准备，不重跑入口。两阶段共享批次总截止时间，各次仍受入口预算约束。短答许可与人物/范围核验成立才调用voice_jev_reply生成，生成或选择失败回到原准备；最后仍通过既有交付许可。主认知流程、JEV2、工具执行保持原路径。

## 尚未完成的方案项

## 验证和边界

114项相关本地假模型/本机HTTP回归通过，之后新增短答生成用例通过（共115个不同测试）。覆盖宿主语音/文字、两阶段不调用普通模型、动态候选、三条输入、问题上限、准备单独回退、短答按许可生成，以及Split/combined和控制/短答兼容。缓存目录存在无害警告。
