# JEV人物终审与情境复核：实施记录

日期：2026-10-06。对应最后确认的分工，本轮实现，不另开工具入口模型调用。

## 当前协议

第一次JEV只输出 `items[{i,person,certainty,why}]`、`level`、`recall_memory`。人物按“还原情境→按程序声纹强度判断→给出结论”处理。`voice.strength=clear/weak/unavailable`来自程序，不让模型另造阈值。需要工具能力选1档，具体使用仍由主认知决定。

新协议去掉 `to/keep/control`。发言不再因为JEV认定不是对匠石说话而被挡住；主认知读取当前原话和此前已完成的JEV情境，自行选择回应、忽略或等待。明确停止仍走程序规则；新人物终审完成不自动打断正在播放的回应。

历史单条action和n/to_jiangshi格式仍保留兼容读取，用于旧调用及旧记录；它们单列，当前模型Schema不再要求这些字段。

## 后台情境与复核

本批事件在第一次判断完成后入JEV片场待办，保存原话、事件ID/时间、原始声音归属、候选、证据强度、短句辅助和第一次结论/依据。失败记failed，规则处理记rule，不冒充正常unknown。主认知触发与独立积累触发使用同一队列；判断未完成的当前批不会先送进第二次。

第二次用单个scene字符串，按“当前情境 / 人物与交互 / 变化与待核”组织，支持多活动、媒体/远端来源、新参与者和场景切换。人物复核指出原判及新依据，只形成后续建议，不改写已生效人物归属，不把多次暂定升级成确认。目标800字符，硬上限1000；新增事件与主认知参考合计3000字符，事件整体取舍、不切断证据与结论，省略项保留取窗信息及归档。

JEV片场作为独立情境参考送入主认知，三档都保留；不当作已确认人物原话或当前最新事实。仍不等待本批后台写场，时间截止保护不把晚到的回应倒灌成当前输入的依据。

补存 `voice_jev_scene` 完整system/user请求，解决此前只有片场结果、缺实际请求的日志问题。历史缺失请求没有补造。

## 影响与验证

新协议减少第一次的判断职责，但原先被拦住的旁人发言现在可能进入主认知，主认知调用量可能增加；本轮没有增加额外工具模型调用。后台仍异步，是否提高真实辨人/接话准确率需运行后验证，不能用本地协议测试代替。

新增集成验证覆盖：无to/keep的新输出能路由主认知；第一次未完成时本批不进入后台；主认知收到情境并能忽略旁人话；第二次实际请求含声音证据与首次判断并可完整保存。

验证结果：Python全量794通过、1跳过；最后播放失败保护调整后，相关27项通过；浏览器界面与播放器2项通过；编译及diff检查通过。没有调用真实模型或麦克风回放，准确率、费用与真实延迟仍待运行观察。
