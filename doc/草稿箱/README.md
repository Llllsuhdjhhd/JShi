# 草稿箱

草稿箱用于某个模块进入设计、实施、代码调试阶段时，集中记录本轮工作材料。它是工作台，不是当前系统规范。

## 使用方式

1. 开始一个模块任务时，复制“模块草稿模板.md”，命名为模块名或任务名。
2. 先写代码现状和目标，再记录想法、实施方案、改动点、调试过程及未决问题。
3. 方案和实现以代码为基准；遇到文档、测试与代码不一致时，在草稿里记下差异和依据。
4. 结束任务时，把稳定且可复核的结论同步到当前文档；草稿标记完成后移入 doc/历史文档/草稿箱归档，保留过程记录。

草稿中的设想、临时结论和未验证行为不得直接视为项目约定。

## 草稿状态

建议使用：调研中、方案中、实现中、调试中、已完成、已搁置。

模板：[模块草稿模板](模块草稿模板.md)
