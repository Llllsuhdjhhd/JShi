# 环境变化与回忆图片

环境观察模型比较当前画面与此前环境描述，输出 description、change_degree、change_reason。

- none：没有环境变化。
- low：细微姿态或细节变化。
- medium：主要活动、人物或物体布局明显变化。
- high：更换环境或整体场景改变；首次观察。

认知存储输入时，保存环境描述和变化标记；只有 medium/high 且照片预算允许时保留事件图片。缺少有效变化等级时不推断为应当存图。实时观察需要的临时图片遵循滚动缓存生命周期，不等于长期记忆图片。

RAG 只检索、排序和筛选文字。最终工作集选出的事件若有实际保留的图片，则批量补充关联引用。相同照片在本轮共用“图片1”等编号，编号写在对应回忆文字中。

主认知启用图片输入需要配置 `JSHI_VISION_COGNITION_IMAGES=true`，并使用支持图片输入的主模型。启用后图片编号和原图一起发给主模型；未启用时明确注明本轮未提供原图，并保留回看引用，不声称看过图片。

本策略从新增事件生效，不批量删除历史记忆和已保留图片。
