## 用途

程序名称JEV1_2。split模式中仅在JEV1_1返回prepare后调用，decision模式则在有效决策入口和必要人物核对后调用；判断直接短答或主认知，选择档位、召回与图片，并按许可生成有限内容。combined模式的相同规则集中展开在[P10-30.0完整合并请求](P10-30.0-第一次JEV.md)，不会额外调用本请求。工具执行仍交既有主认知及工具流程。

```text
P10-40.0 完整请求
├─ .1 system：回应方式、能力与材料选择、有限生成及本批Schema
└─ .2 user：入口结论、可处理原话、同版现场、许可与必要补充
```

## 输入

沿用JEV1_1同批身份、范围、片场版本、纠正代次和时间锚点，不重复认人或装入声音候选。任务摘要在选档之前就可读取，避免档位与工具材料加载相互依赖。

块内对象／数组使用紧凑JSON，片场与参考正文直接作为文字。空的可选材料块连同标题省略；模板中的变量在程序侧替换，不发送变量名。图片仅在入口／合并请求有实际媒体时随input_parts提供，JEV1_2不重复带图；main_image另控制后续主认知带图。时间在同一批次只压缩一次，两个阶段共用P、E、I/C、Q、T/M映射及时间基准。

严格输出route、level、recall_memory、main_image、reply、waiting_reply、reason；所有字段必填，不允许额外字段。level仅整数1/2/3，布尔值不能充当整数；reason非空且最多100字符，reply最多160字符，waiting_reply最多16字符。

程序复核直接短答许可、入口direct、redirect或空闲keep、参与者confirmed且匹配许可对象、没有重叠／待接续、L3／不召回／不带图。未通过时交main，不交付越权短答。等待接话还须通过实际许可、档位等待预算和冷却；忙碌keep、歧义及停止独立操作均静默。include在没有实际图片时降为omit，后续继续保留原图去重与能力检查。

main不保证必须开口。stop+prepare强制L1且本轮交付静默，工具操作仍由主认知决策。第二阶段异常保留入口身份与已生效控制，失败的JEV不生成回复；独立文字入口非过期、非已确认stop的故障转交主认知，由主认知决定回应，页面明确标记降级。声音失败仍保持不开口，过期及stop失败不被降级覆盖。实际召回、带图、工具选择、结果复用及执行使用现有流程，不新增未经实现的后续补取能力。固定提示词及Schema不变，降级是程序行为，当前生产例子待补充。
