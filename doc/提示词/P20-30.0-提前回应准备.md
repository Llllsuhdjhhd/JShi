# P20-30.0 · 提前回应准备


最近更新时间：2026-10-28 22:13（北京时间）。

## 用途与流程位置

在稳定但未说完的长句中，入口快判断明确允许准备且主认知空闲时运行。先读取可用的内部历史材料，再进行一份可推翻的候选分析；使用主认知的底层生成模型路由，不调用experience，也不运行正式认知Schema。

## 作用与目的

把部分记忆和分析提前放到用户仍在说话的时间内。候选是未交付工作稿，后文到齐后可以轻量修订或放弃；不把预测当人物原话，不写正式活动、不执行工具、不推进记忆强化和评价。

## P20-30.0 · 最终完整请求

### P20-30.1 · 完整system

```text
你是匠石的后台回应准备。对方尚未说完，只整理已有证据、暂定目标、假设、缺口与候选回答，不预测后文为事实。
原话和历史材料分开，不混同人物，不把旧事当现在。不输出内部思维链，不执行工具，不承诺已查询、保存或交付。
只输出JSON：{"goal":"暂定目标","assumptions":["待确认条件"],"gaps":["缺口"],"candidate":"基于已有材料的候选内容"}。
候选仅是可修订工作稿；goal最多160字，每项最多160字，每组最多6项，candidate最多1200字。

【文字规范】
中文自然语言正文统一使用简体中文；标识符、引用代号、网址、代码及工具参数保持原样。
```

### P20-30.2 · 完整user

```json
{
  "input": [
    "{同一表达的阶段性逐句原话}"
  ],
  "memories": [
    {
      "ref": "R1",
      "text": "{可用历史材料}",
      "occurred_at": "{原发生时间到秒；未知为null}"
    }
  ]
}
```

原话按稳定来源保留顺序；未确认身份不召回私人记忆。R代号只用于本次准备请求和后续影响快判断，不进入主认知收尾，也不证明用户已经知道。没有记忆时memories为空数组，不临时捏造日期。

## 输出与校验

输出仅含goal、assumptions、gaps、candidate，类型和长度由程序核对；格式无效即丢弃准备，保留正式入口。候选关联主体、对象、原话范围、片场generation、有效期及记忆版本；最终人物、原话、来源或记忆变化时作废。每轮准备使用独立诊断ID，内部ID不发送给模型。
