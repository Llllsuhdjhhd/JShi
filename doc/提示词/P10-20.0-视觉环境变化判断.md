## 给人看的说明（以下全部不发送给模型）

<details>
<summary>程序位置、接口参数与维护细节</summary>

定义：[vision/model.py](../../src/jshi/vision/model.py) · `VisionModel.observe` / `describe(structured=True)`；服务：[vision/service.py](../../src/jshi/vision/service.py)。日常`_observe`只传当前图；`compare_images`显式提供当前图、历史图和采样时差，检查主体与时间顺序、执行云端开关及调用预算。首次观察用记录reason=initial表达初始化，变化等级仍unknown。

| 字段 | 含义及程序行为 |
| --- | --- |
| description | 当前图片可见内容，必须为非空字符串；不混入旧图或旧描述 |
| change_degree | unknown/none/low/medium/high；无比较材料时observe强制unknown，服务日常观察也强制unknown |
| change_reason | 比较依据或缺口；无比较材料时observe强制为“未提供历史比较材料，仅完成当前观察。”；比较分支目前未单独强制非空校验 |

**接口参数、校验及维护边界**

实际请求为一条user，文字先于图片，response_format.type=json_object；模型、max_tokens=1200、stream=false及DeepSeek非思考配置沿用P10-10。非法JSON、空描述或非法变化枚举会抛错；程序不保证模型对真实变化的语义判断正确。

旧描述最多3000字符、时差说明最多300字符。兼容scene参数不进入请求，不提供对话或片场。未知时间不能替成当前时间；图像拍摄时间与描述完成时间由宿主分别保存。服务时差为“历史图在当前图前&lt;整数秒&gt;秒。”。

单图不能断言人物进出或环境切换；两图也不能证明采样间隔内的过程。共同正文修改时同步P10-10；组包和字段变化同步索引及已有说明，旧实际例子按版本留档。

其他可选组合：直接describe调用有观察问题时，在共用正文后追加P10-10的问题行；日常observe不传问题。若旧描述与历史图同时提供，在情况二的共用正文后、图片说明前插入情况三的旧描述行。正文、材料和尾部顺序与程序一致，仍只发一次请求。
