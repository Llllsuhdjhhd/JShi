### [P10-30.0 · 第一次JEV](P10-30.0-第一次JEV.md)

用途：主认知前终审人物，选档位、召回、带图及短聊路由。

五种前台选择：JEV直接回答、L1/L2/L3短接话、静默交主认知；直接回答受许可约束，短句采用30秒冷却，静默仍保留认知档位。此前真实测试有版本边界，本轮真实调用待补。明确口语停止绕过声纹、合批及模型；本地声音比对等待有上限，诊断保留其耗时。

等待接话：`JSHI_JEV_WAIT_ACK_ENABLED=false`，当前及默认关闭L1/L2/L3等待短句，功能保留，设为true可恢复；不影响JEV直接回答或主认知档位选择。语音和文字均受许可及展示/播放前开关控制，不另增模型调用。

接续时效：文字和语音均在组包前按连续对话筛选；默认静默超过300秒不带旧原话接续，配置`JSHI_JEV_CONTEXT_IDLE_SECONDS`。片场不按此阈值过滤或修改，主认知片场逻辑不变；原始历史不删除。弱声纹/未确认句的 JEV 组包可带同 track 的 `continuity.same_cluster` 与候选排序，不降低全局声纹确认门槛。最近更新：2026-10-14 15:17（北京时间）。

```text
P10-30.0 最终请求
├─ .1 system
│  ├─ .1.1 入口判断规则
│  └─ .1.2 本批输出Schema
└─ .2 user
   ├─ .2.1 本批原话、人物候选与声音证据
   ├─ .2.2 JEV片场、近期接续、播放及短聊材料
   └─ .2.3 有效视觉材料与按条件附带的图片
```

模型连接见[模型设置与路由](../模型设置与路由.md)。页面只选一个全局模型、填写API Key及思考强度，一次保存用于所有用途；不显示备用选择，保存后取消旧备用链。仅更换服务及API承载格式，不修改上述提示词正文或L1/L2/L3分支。Gemini以systemInstruction与contents承载原system/user，图片保留关联文字与内联附件；与兼容接口的messages格式不同，但发送的语义材料不增减。

- 名称下面先写用途，再画组成树；全文始终在完整请求名下集中展示。树是给人看的说明，不发送给模型。
- 不存在的system明确写“不发送”；来自外部引擎的内容明确来源，不补造。
- 一次只选择命中的人格、档位或执行分支，不把多个版本叠加。
- 共用材料属于各请求的下级组成，不另建平级文档。实际例子不足标待补，不编造。
- 编号是目录定位，不代表新增调用次数。文件名保留，避免旧链接失效。
