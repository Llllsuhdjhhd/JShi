### P10-05.0 · 火山语音转写热词与语境

最近更新时间：2026-11-10 10:31（北京时间）。

用途与流程位置：浏览器原声进入火山流式ASR、补识别或分离音轨转写前，提供助手名字的写法与场景背景；输出转写交声音对齐和JEV。语境只帮助转写，不确认人物、不授予接话许可，也不把“降十”“暂时”强替换成“匠石”。

组成：本调用没有Chat system/user角色；完整请求为16kHz单声道PCM及request参数。`request.corpus.context`是JSON字符串，含现有`hotwords:[{word:...}]`，语境非空时追加`context_type:"dialog_ctx"`和`context_data:[{text:语境}]`；两项均空则不发corpus。主识别、补识别与分离转写共用`VolcVoice.asr_request`，不是新增模型调用。

当前语境全文：语音助手的名字是匠石，工匠的匠，石头的石。现场也有人与人交谈，不是每句话都在呼唤助手。

在线请求默认`enable_nonstream:false`（`JSHI_VOICE_ASR_TWO_PASS=off`）；显式on可恢复句末二遍识别。实测曾出现一遍“匠石”被二遍改为“暂时”，关闭后授权28秒原声两次开头、末尾均为“匠石”。这仍是服务端最终结果，不把临时字幕冒充最终结果。

配置：`JSHI_VOICE_ASR_CONTEXT`可覆盖或设空关闭，最多500字符；`JSHI_VOICE_ASR_HOTWORDS`沿用现有词表。本项只传简短名字说明，不传人物长ID、时钟、历史记忆或伪造对话。来源：`src/jshi/voice/config.py`、`volc.py`；补识别复用同请求构造。当前只维护索引，不另建全文文档。

官方格式依据：[热词与上下文](https://docs.volcengine.com/docs/doubao-voice/hot-words-and-context?lang=zh)。授权28秒原录音中，补名字背景后末尾单次呼唤4次识别为“匠石”，当时仍开启二遍，开头误识别为“暂时”；该结果为本轮关闭二遍前的对照，不能与新配置混用。实测请求与云端包存于本地`test_runs/voice-20261110/hotword-name-context.json`及`hotword-context-repeat-*.json`。
