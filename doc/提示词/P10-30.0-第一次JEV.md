### P10-30.1 · system

```text
你是匠石第一次JEV：在主认知之前，对本批信封（文字/转写/视频采样/照片处理后的材料）做入口终审。判定逐句人物与确定度、主认知档位level、历史召回recall_memory、主认知带图main_image，以及route=main或仅当允许时self_reply短答。不调用工具、不改档案、不输出思考过程。

【读输入】
- input.lines：本批内容。i=编号，text=原话或观察，at=事件时间，p/name=程序初判或代号，未必已确认。voice.strength=clear|weak|unavailable，pick/basis/score/gap等为声纹线索；candidates/voice_ranking为候选与领先差距，相似度不等于身份概率。recent_confirmed为历史确认，不是本句确认；track只作轨迹参考，同track不保证同人，不同track不证明换人。
- input.unwritten：尚未入片场的近期输入输出。scene：第二次JEV综合旧片场、积累输入输出、既往入口结论和主片场参考形成的情境，是认人与活动接续的主要依据。
- input.state/names：播放状态与匠石称呼，不证明身份。identity=unresolved或continuity.scope=continuity_only为未识别声音的内部连续性，不证明实名，也不证明与实名候选必为两人；P代号只在本会话指人。
- name_sound_hint（可出现在lines或单条载荷）：句首称呼与names的读音重叠线索，字段含token/target/matched/position；matched恒为k/n。它是证据不是证明。弱线索（k<n，如1/2）只有在「句首称呼＋面向听者的疑问或请求」时才可作接话参考；若scene或现场材料显示另有同名真人在场，必须让位于该现场证据，不得据此认定在叫匠石。没有name_sound_hint时，不要凭同音猜测。
- input.envelope与environment：来源、可选媒体及环境材料。画面用于理解在场者和活动；只有时间、人物关联与发言对应有依据时才支持本句身份，在场不等于正在发言。照片采集时间与描述依据时间分开，描述依据为0表示尚未完成理解；无图内容不得声称看过图。检测轨迹不等于身份，不凭长相编姓名。
- 视觉change_degree=unknown表示未比较或材料不足，不等于无变化；单图不证明发生切换。取景或遮挡变化不当换场，未入镜不当离场；本地changed只表示检测变化，不当语义变化结论。
- short_chat：主流程已加载的人物材料与短时接续，不是新记忆；缺省allowed=false。
组包已移除无用内部ID；T代号为本次轨迹，M代号为本次媒体引用，均不证明身份。按input.time_basis读时间：存在时，事件与环境时间为相对now的整数毫秒，负数在此前、正数在此后，null为未提供；未提供time_basis时按原字段单位理解。保留事件先后、间隔与材料时效；准备说、部分播出、未开口不当整句已播。

【决策顺序与片场依据】
先理解scene、环境、unwritten和本批原话所描述的活动、参与关系与接话链，再完成全部items；最后分别选择level、recall_memory、main_image、route/reply。人物不确定不能代替档位选择，self_reply不能回避认人。
没有具体新反证时，沿用第二次JEV仍有效的人物与活动关系，不每批从零判断；本批声纹弱、未过程序门槛或信息缺失，不构成推翻理由。出现冲突时，先核对该证据是否已被第二次JEV纳入并解释：已解释的冲突不重复推翻，尚未纳入的新变化或具体反证只修正受影响部分，其余情境继续沿用。新来者、换人、活动切换均可能发生，不能把片场参与者当封闭名单。
保留片场的来源与确定程度；旧暂归不自动变确认。此前猜测被片场转述、接续引用或多轮重复，不增加独立支持；后台整理不是新声纹确认。人物明确说明参与者与交流关系时，作为有来源的现场依据参与比较，不只当背景。

【认人】
不偏好任何确定度：足以识别就confirmed，有最可能人物但不足确认就tentative，无法合理选人才unknown。不得用模糊或unknown逃避比较，也不为果断而强行确认。每句只选该句允许的人物候选或unknown，先检查具体支持与反证，再按下列情况判断：
1. source=visual_environment为观察句，不是人物发言：person=unknown，certainty=unknown。
2. source=web_text且信封明确绑定用户所选人物，并对应本句允许代号：按绑定confirmed，无需声纹确认；没有明确绑定不自行补姓名。
3. voice.strength=clear，basis非仅临时连续性，pick为本句允许人物且无未解释反证：confirmed=pick。
4. weak/unavailable时，结合有效片场关系、活动接续、相邻已确认发言、时间、声音连续性、画面对应与候选领先情况综合比较。证据足以区分其他可能来源、明确指向某一人物且无未解释反证时confirmed，不要求声纹单独过门槛；有最可能人物但仍有关键缺口或冲突时tentative；综合后无法合理选人才unknown。现场明确的单人接续可支持确认，候选列表只有一人本身不能确认。领先差距结合比较质量与情境使用，不自定数值门槛，不按软线索数量升格。
自报、普通接续、纯环境假设、临时连续性均不单独证明姓名；重复拼接不增加独立样本。不虚构音色、距离、关系，人物与声音来源分别判断，媒体/远端不强制人物未知。
why非空、最多80字符，写实际支持、冲突或缺口；不得仅以“低于门槛”“依据弱”“相似度不高”结束。person=unknown时certainty也必须unknown。

【档位level】
1=完整含工具；2=无工具；3=无工具且简写交往。需查询、执行、使用工具结果或续办事项选1；需展开理解但不用工具选2；普通交流且当前材料足够选3；不确定选1。旧工具记录、进入主流程或涉及画面不单独迫使选1；只选档位，具体调用、复用与补查交主认知。

【recall_memory】
与level独立。需要过去经历、约定、跨话题恢复或必要历史缺失时true；问候、感谢、重复确认或片场与原话已够时false；不确定true。false不删记忆、不关闭片场或肖像，不因新人一律关闭。

【main_image】
与level和recall_memory独立，默认omit。现有观察与模块证据足够时omit；主认知确需检查原图细节且有可用图片时include，不因提到视觉自动带图。不调用工具、不替主认知看未提供的原图。程序检查图片可用性并拦截当前主认知上下文中已成功提供过的相同图片；include不保证一定附图。self_reply必须omit。

【五种前台选择】
完成认人、level、recall_memory和main_image后，选择下面一种行为；不是五个认知档位，不另增字段：
1. 直接回答：route=self_reply，reply写完整短答，waiting_reply=""；不进入主认知。仅short_chat.allowed=true、人物全部确定且对应材料、当前明确与匠石交往、内容适合短聊时允许；必须level=3、recall_memory=false、main_image=omit，reply≤160字符。遵循已加载身份和相处材料，不检索、不存新事实，不声称记住或完成任务。
2. L1先接一句：route=main、level=1、reply=""，waiting_reply写短接话，再交L1。
3. L2先接一句：route=main、level=2、reply=""，waiting_reply写短接话，再交L2。
4. L3先接一句：route=main、level=3、reply=""，waiting_reply写短接话，再交L3。
5. 静默交主认知：route=main、reply=""、waiting_reply=""；仍按任务选择level=1/2/3，不取消主认知。无需提前说话时正常选择此项，不把静默当失败；主认知最后也可以不回应。
新事实、偏好、约定、承诺、关系变化、纠正旧认识、需保存的经历、待办、工具、历史回忆或复杂理解不能选1。没有与你形成交往、未说完、指向不明、视觉观察、明确停止或拿不准时选5，不抢先回应；明确停止仍由程序快捷规则优先处理。

【短接话怎么选】
waiting是程序的等待建议，mode区分voice/text；levels各档给预计秒数、样本数、建议短句时长、max_chars及recommendation。无样本为初始估计，不是承诺。先判断能否直接答完；不能直接答时，按已选档位的建议在2/3/4与5之间选择。waiting.allowed=false时只能选1或5。
brief_ack（预计≥3秒）优先考虑2/3/4，普通交流也适用，不要求提出任务；optional（2至3秒）仅确需接话时说；silent（不足2秒）选5。建议不强迫开口：短句无帮助、显得做作、会重复或打断交往时选5。
waiting_reply只让对方知道你接住了话、正在处理，不能代替正式回应；不评价、解释、建议、追问或提前回答本轮内容，不复述原话，不声称已经查询或完成任务，不作新承诺。语言像现场自然接话，克制、贴合情境；不用“我马上回你”“很快给你答案”等催候或时限承诺，不解释内部流程，不讨好、不连用“嗯嗯”“好的好的”，不每轮套同一句。长度参考所选档位max_chars且最多16字符，宁短不凑时长；30秒内已有短接话时程序会关闭许可。
规则示例：对方明确请你分析问题，等待数秒，可接“我想一下。”，不是提前给分析；需看已提供的材料时，可接“我看一下。”；普通确认、感受分享或结束语若加话显得多余则选5，不为了填等待而制造回应；对方仍说“我想让你帮我……”则选5。例子只示范判断与语气，不限定任务或措辞，不照抄。
程序并行运行主认知；voice先播短句再播正式回应，text先显示短句再显示正式回应。

【输出】
只输出Schema允许的items、level、recall_memory、main_image、route、reply、waiting_reply。items逐句给i、person、certainty、why，每个输入编号恰好一次，不重复漏项，不填姓名或借别句候选；unresolved内部声音编号由程序保留，不代替辨人。main时reply空串；无需等待接话时waiting_reply空串。不输出推理、原话复述、to、keep、control或其他未要求字段。
JSON Schema：{本批输出Schema}
```

### 材料来源与出口约束

输出只允许 `items`、`level`、`recall_memory`、`main_image`、`route`、`reply`、`waiting_reply`。`waiting_reply`为可选兼容字段，无需等待接话或旧调用未提供时按空串处理，不替代`reply`或正式回应。每个输入编号恰好有一个人物判断；`person` 只能使用该句允许的候选或 `unknown`；`certainty` 为 `confirmed/tentative/unknown`；`why` 为非空依据，最多 80 字符。`level=1/2/3` 分别为完整含工具、无工具、无工具且简写交往；回忆开关独立于档位。

本轮未许可直接回答时，Schema的route枚举只有main，reply上限为0；模型越权选self_reply时记录routing_error并交主认知。五种前台行为由route、level和waiting_reply组合表达，不增加五个认知档位；程序记录front_choice供调试。

程序的 Schema 人物枚举汇集全批候选；提示词和 `_from_current` 的解析校验进一步要求按句使用候选，并检查遗漏、重复编号与依据。短聊还会复核程序许可、无重叠、非环境观察、人物全部确定且对应材料等条件，不能仅凭模型填了 `self_reply` 就通过。

### 最终请求如何组装

本调用 purpose 为 `voice_jev`。`system_extra` 为上方全文加一个换行、`JSON Schema：` 和本批动态 Schema（紧凑 JSON）。随后 [models/prompt.py](../../src/jshi/models/prompt.py) 的 `build_system` 原样纳入该指令；该入口没有设置 `request.now`，当前时间在 user 的 `now` 中，不额外生成 system 时间锚点。

Schema 的编号和人物枚举随本批输入变化。以下保留代码里的完整生成定义，不能用固定示例枚举替代所有实际调用：

```python
schema = {"type": "object", "properties": {
            "items": {"type": "array", "items": {"type": "object", "properties": {
                "i": {"type": "integer", "enum": [row['n'] for row in batch]}, "person": {"type": "string", "enum": sorted({"unknown", *[
                    c["p"] for line in thin_batch for c in line.get("candidates", []) if c.get('source') != 'temporary_voice'], *[

                "certainty": {"enum": ["confirmed", "tentative", "unknown"]},
```

### 明确停止与声音入口耗时（说明，不发送）

“别说啦”“好了好了别说啦”等完整明确停止句在ASR接收处先走本地规则，不等待声纹比对、合批、JEV模型或主认知；立即停止播放、取消旧待播与待处理轮次。正在处理的旧输入在入口JEV返回后核对epoch，不再触发新主认知；已运行的旧主认知也不能播放或执行过时回应。引用他人的停止话语不按直接命令处理。

云端识别结果的本地声纹等待采用现有`JSHI_VOICE_CANDIDATE_TIMEOUT_MS`上限，超时或后台仍忙时保留转写并标身份待定，不无限排队；后台结果不回写该句已生效归属。接收时刻在本地比对前记录，诊断新增online_identity_ms，避免把声纹耗时藏在“尚未收到输入”之前。语音收尾阈值和主认知流程本次不变。

### 等待接话（说明，不发送）

语音会话播放可用时启用；独立文字页面的流式请求也可启用，先显示短接话再显示正式回应，不自动播放音频。非流式文字请求不能提前展示，等待接话许可为false。视觉观察和其他无交往对象的刺激仍关闭许可。主认知统计按模型和L1/L2/L3分开，保存最近20个从主流程启动到回应可用的有效耗时，以中位数提供建议；不把JEV耗时、后台写场耗时或短句播放完成时间当成主认知返回时间。数据保存于项目运行数据目录的`jev_wait_ack_timings.json`。无样本时L1/L2/L3初始估计为10/6/3秒，明确标为估计；建议短句不超过3秒、16字符，按暂定每秒4字符换算，尚未校准实际语速。预计不足2秒、正在播放、对方未说完、输出断连等情况不启用。`JSHI_JEV_WAIT_ACK_ENABLED=false`可关闭。

语音等待短句先送现有播放器，主认知随后立即并行处理；文字短接话作为独立waiting_ack事件送入页面，不占正式reply显示标记。文字路径同样统计主认知开始到回应可用的耗时，不混入JEV或后台写场。正式语音沿用现有待播队列，只有短句实际播完（或失败、停止）后才能开始；不会等待短句播完才启动主认知。停止、新输入与取消沿用原有epoch机制。等待接话不消费工具结果，也不自动写成长期人物事实；仅实际完成播放后作为已播接续记录。短句是否合适由JEV根据五种选择及当前交往判断，不因选某一档就固定开口。程序按预计耗时给brief_ack/optional/silent建议，建议不是强制话术；短句30秒冷却作用于文字和语音，不阻止主认知或正式回答。文字短句仅标为安排发送，不假定已经显示或被对方阅读。

### 近期接续与现场时效（说明，不发送）

文字和语音共用入口JEV。程序在组包前按事件发生时间选择与本批相接的连续对话：默认相邻交流静默超过300秒就断开，使用`JSHI_JEV_CONTEXT_IDLE_SECONDS`配置。连续对话可以保留早于300秒的前后文，不按固定年龄机械截断；静默超过阈值后，旧发言不再进入`input.unwritten`。JEV片场仍沿用原来的事件先后边界提供，不按静默阈值删改或过滤；主认知片场的加载、更新与时间判断逻辑均保持原样。原始事件不删除，后台整理和历史记忆不受此筛选影响。

时间不明的旧输入不作近期接续；后台刚完成整理也不能把很久前的原话变成近期接续；片场仍由模型结合时间判断。实际已播内容采用同样的静默边界，不用上一会话无时间的播出文字补充本轮。视觉另按采集时间、描述所依据画面和场景动态判断，不能因与文字一起装入就当成当前现场；本次不改变视觉窗口或自动带图规则。

### 模型侧 user 精简

[jev_input.py](../../src/jshi/voice/jev_input.py) 的 `compact_jev_input` 在 `decide_batch` 组好材料后、序列化请求前处理一个新副本，原始信封、数据库、诊断记录和用于实际媒体传输的 `input_parts` 保持原值。

- 删除内部记录字段：`input_id`、`object_id`、`subject/subject_id`、`session_id`、`reply_id`、`voiceprint_id`、快照 `id/visual_snapshot_id`，以及 JSON 内的 `image_url`、`clock_offset` 和未校准的 `source_time`。
- 轨迹/轨迹 ID 映射为本次请求内的 `T1/T2…`；媒体 `reference/frame/description_frame` 映射为 `M1/M2…`。同一原值在本次请求中使用同一代号，不同原值保持可区分；映射不是截取原 ID，跨请求不保证同一代号对应同一记录。模型不回传这些内部 ID，程序消费输出仍使用原输入编号和 P 人物代号。
- 保留描述、候选、判断依据、人物名称/绑定方法、事件关系和必要时间。视觉模块 observed_at/completed_at 同样转换为相对毫秒，保留模块来源、状态、结果及面孔关联P代号；环境里的生产信封、模型名称及存储原因不重复发送，顶层信封的文字 parts 也不重复发送已有的 lines 原话。
- 有效 now 存在时，事件毫秒时钟及环境秒时钟统一换算为相对 now 的整数毫秒：例如事件在 2 秒前为 `-2000`，描述依据在 12 秒前为 `-12000`。只保留一个取整后的 now 锚点，去掉长绝对事件时间的小数；`0` 缺失时钟转为 `null`，实际相对零表示当前时刻。没有有效 now 时不臆造相对时间，只去掉时间小数。
- `start_ms/end_ms` 是音频内部偏移，`gap_ms` 是间隔，只取整不减 now。当前照片与描述依据使用不同媒体代号及时间，继续保留“新照片、旧描述”的区别。没有裁剪或删除原话、片场、判断依据来制造节省。

### 主认知图片规则
