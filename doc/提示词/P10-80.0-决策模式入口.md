# P10-80.0 · 决策模式入口

最近更新时间：2026-10-28 21:28（北京时间）。

[返回提示词索引](README.md)

## 用途与流程位置

选择decision后，对单条无重叠的文字或已转写语音，判断交往、完整度和控制。输出经程序组合为入口，再进行必要的人物核对及按需JEV1_2。多条混合、需图像／环境判断、未提供事件或材料超预算直接走split。音频关联不等于必须看图。

## 作用与目的

四题独立读取同一材料；不生成回复、人物归属或解释文字，不假设能读到其他题的结果。程序检查供应商对应的address／expression／stop／background／wait门槛，组合路由，失败或矛盾回退split一次。

模型不提供decision_reason和decision_refs。程序诊断说明明确标注“程序组合决策入口”，引用是提供材料关联，不冒充模型给出的推理依据。

## 最终请求组成

```text
P10-80.0 完整请求（原生System One，无聊天system/user）
├─ model：已选供应商模型
├─ state.material：同版entry_text材料
└─ questions：address、expression、task_effect、work_after_stop四个choice
```

## 程序组合与边界

- direct＋stop且无独立操作：stop＋background；存在独立操作且complete：stop＋prepare，静默main＋L1。
- other＋keep且complete：background；背景未完或范围不明回退完整入口，避免与宿主未完保护冲突；明确direct、incomplete＋keep：wait；direct、complete且keep／redirect：prepare。
- 本版只支持整批一条表达，process或pending由程序映射本批I引用；混合范围不让模型猜数组。
- 停止后的操作关系不清、必要题uncertain、置信不足、非法返回均回退split。已有明确停止且已执行时，后续回退保留停止状态。
- 原话、声音证据及人物记录仍保留，背景／等待仍做必要人物核对并供JEV2整理。
- off时不请求，shadow时split正式执行、决策只读异步观察；active才采用本结果。选择模式持久保存，单批回退不修改选择。
- 默认各门槛0.90是实验起点，未做两家真实中文样本校准，不等于90%准确率。

## 程序来源与长度

`decision/entry_policy.py`定义四题及组合，`voice/jev_serial.py`读取同版快照和校验入口，`voice/jev_decision.py`把工作线程请求送至宿主事件循环，`decision/service.py`完成供应商配置快照、用途预算和审计。

固定questions按实际紧凑JSON计845字符；state.material文字模板244字符。动态材料与模型名另计；无system/user字数。问题定义由本次程序导出，未将展示缩进计入实际发送长度。
