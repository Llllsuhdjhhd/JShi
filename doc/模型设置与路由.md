# 模型设置与备用路由

当前生效配置（2026-10-14）：统一模型为`deepseek-v4-flash`、无备用；主认知保留用户指定的轻度思考low，入口JEV恢复关闭思考。此前全局low覆盖JEV原有disabled，导致两次直接回答约9.5/7.9秒；已在运行服务热修正，并在设置组装中固定JEV快速策略，重启或重新保存全局配置仍保留。其他用途本次不调整。不能把low当成固定短思考预算，实际主认知延迟仍应查看记录。

原启动配置核对：skills.json里主认知enabled/low、写场enabled/high、工具规划及整理disabled；voice_jev未单列时沿用default_profile的disabled。这次只恢复JEV关闭，不改回后台写场high或其他用途，不增加页面逐项设置。统一的是模型服务与型号，入口快判断是程序固定策略。Gemini3不能完全关闭时，入口用minimal，3.8 Flash用low。

2026-10-14思考延迟实测：同一份当前JEV固定提示词与Schema、合成问候“早啊”，不载入生产片场、历史、回忆或图片。Qwen3.5 Flash按关闭→轻量→轻量→关闭各调用一次，max_tokens=1024。关闭两次1.737/1.991秒，思考token为0；轻量两次8.172/9.054秒，每次实际思考512 token。中位数1.864对8.613秒，约4.62倍。四次都能解析JSON并包含所需字段；这不证明正式场景语义判断质量或主认知完整延迟。测试没有修改运行配置。完整请求材料、usage和时延见[思考实测报告](../work/qwen-thinking-latency-20261014.json)。

模型调用提示默认隐藏。在“全局模型设置”勾选“显示对话中的模型调用信息”即可显示，关闭时隐藏已有及后续模型调用行，浏览器保存选择；文字和语音路径统一使用此开关。失败、额度错误及其他交往提示不隐藏，模型设置与后台记录不受影响。旧服务发来的付费模型notice也兼容分类，刷新页面即可使用默认隐藏逻辑。

## Qwen3.5 Flash接入

用户已允许付费，关注单次输入不超过128K的计费档及与DeepSeek的对比。页面新增“阿里云百炼 Qwen”，支持`qwen3.5-flash`及固定版本`qwen3.5-flash-2026-02-23`。北京兼容接口预填`https://dashscope.aliyuncs.com/compatible-mode/v1`；如百炼提供业务空间API Host，填写该空间的兼容地址。密钥在服务连接填写一次，也可来自`JSHI_API_QWEN_API_KEY`或`DASHSCOPE_API_KEY`；不改其他服务，不自动切换当前DeepSeek。也可读`DASHSCOPE_BASE_URL`（默认北京兼容口）。2026-10-14 速度刀约定：`qwen3.5-flash`只进**兜底链**（`gemini` flash-lite 之后、DeepSeek 之前），不上热路径；热路径仍优先`gemini-3-flash-preview`。程序把 Qwen 标为慢路径降级超时（与 lite 同档），不自动改用户已保存的首选。

用户最终选择先试轻量思考：页面选择Qwen首选时默认轻量，程序发送`enable_thinking=true`并限定思考预算512 token；关闭或最低发送false，充分的预算为8192。思考预算不是延迟保证，实际质量及速度由用户后续测试。不向百炼发送DeepSeek的thinking/reasoning_effort字段。原system/user及图片材料仍用既有兼容组包，提示词字数不变。

用户不需要额外对比功能，未交付对比按钮或接口，也未代为调用新模型；原首选连接测试保留，只有用户点击才运行。正式请求的输入量以服务返回usage为准，目前未接入Qwen精确预分词，不能把本地字符数或其他模型的token数冒充Qwen计费token。128K在此指用户关注的单次输入计费档，未添加按字符数假装精确token上限的裁剪。

百炼使用免费额度后可能计费，用户此次允许付费；若之后改为仅免费，需在百炼启用“免费额度用完即停”。[官方思考参数](https://www.alibabacloud.com/help/en/model-studio/deep-thinking)、[官方价格与128K档](https://help.aliyun.com/zh/model-studio/model-pricing)。当前仅完成模拟参数与对比路径测试，未做Qwen真实API测试。

当前运行配置（2026-10-13）：用户因正式对话异常要求切回DeepSeek，已通过本机设置接口热切全局为`deepseek-v4-flash`、关闭思考，无备用模型。此前轻量思考下两次JEV直接回答分别耗时14.7秒、9.2秒，未调用主认知；本次先关闭思考，后续实际延迟仍待验证。主认知、JEV、写场、自省、工具规划整理及视觉共用该设置，重启后保留。免费服务固定短句的连通成功不代表正式对话、结构化输出或时限适配已经验证，暂不继续作为生产默认。

在对话页面的“设置与调试 → 全局模型设置”选一个模型，在同一处填写API Key、选择思考强度，再点“保存并使用”。模型与服务合并为一个下拉框；保存连接与切换模型是同一次操作。地址自动预填，业务空间专用地址等特殊情况才展开高级设置。API Key已配置时留空保留，不返回完整密钥。主认知、JEV、写场、自省、工具规划整理及视觉共用这一模型，页面不显示第二、第三、第四选择，保存后取消旧备用顺序。各用途实际调用可折叠查看；原路由能力保留在程序内。外部工具执行引擎、ASR、TTS及本地检测模型不属于此LLM设置。

保存不会发出测试请求。正在进行的请求保留开始时的模型顺序，新请求采用新设置；重启后页面设置继续生效，覆盖启动配置。恢复“沿用启动配置”移除全局覆盖。已有对话、片场、记忆与播放不清空。开发时已按用户授权导入手册三家服务连接，并将已保存的主认知免费首选与备用顺序迁移为全局，不自动追加付费模型。

单模型保存后请求失败就显示错误，不自动换家。旧多模型配置在用户重新保存前仍按原顺序使用；流式正文已输出后不拼接另一家继续回答。百炼错误显示服务、模型及安全错误码分类，区分FreeTierOnly、Arrearage、未开通、无效Key等，不展示原始错误正文中的潜在敏感内容；文字输入失败在对话中显示原因。2026-10-13两次实际Qwen输入收到HTTP403额度类拒绝，但旧版未保留具体错误码，不能直接断定余额不足或128K超限。

OpenRouter只接受带`:free`的模型。DeepSeek是付费服务，若配置必须排在最后；保存时提示付费兜底，调用时语音会话显示付费提示，模型面板也显示付费模型。可不配置DeepSeek，免费备用都不可用时就失败，不自动追加付费服务。Gemini、Cloudflare和OpenRouter在用户已经授权的范围内按保存顺序自动路由，不逐次确认。

思考强度与L1/L2/L3提示词档位独立。DeepSeek支持关闭、轻量、充分；Gemini3使用对应thinkingLevel，完全关闭不可用，3.8 Flash也不支持minimal。Gemini的最低不保证完全不思考；普通兼容服务不发送DeepSeek专属thinking字段，使用其默认思考设置。Gemini适配保留既有system/user正文、图片关联文字及内联图片，不改写提示词，不额外发送原始音频。视觉模块也保留原描述与比较提示词。

“测试首选连接”只发送固定的`Reply with OK only.`，不发送对话、回忆或图片，不保存配置，不尝试备用，也不证明正式提示词质量或实际语音延迟。测试实际消耗所选服务的额度；选择DeepSeek时页面已明确标为付费。

连接与路由保存到运行数据目录的`model_settings.local.json`，临时文件为`model_settings.local.tmp`，两种文件已加入Git忽略。页面只显示是否已有密钥，密钥输入留空表示保留；完整密钥不会通过读取接口返回。保存及测试接口要求同源Origin。初始凭据仍可来自.env；网页配置不修改.env或skills.json。

2026-10-13已用固定短句在本机实测：Gemini3.6 Flash流式返回OK约3.31秒；Cloudflare Scout返回OK约2.27秒；OpenRouter免费模型返回OK约4.00秒。原Gemini请求曾被403/1010拒绝，改用明确的JShi User-Agent后恢复；程序显示服务、模型及固定的错误分类，已知1010可尝试下一个已配置服务，其他普通权限403仍不自动切换。报告见[固定短句实测](../work/model-free-smoke-20261013.json)。这些结果仅证明当次连接，不代表正式提示词质量、剩余额度或语音延迟。未发送真实对话、回忆或图片，未调用付费DeepSeek。
