# 视觉流程与接口

最近更新时间：2026-10-12 16:20（北京时间）。

视觉是独立信息来源。以本地检测和跟踪为基础，各模块对同一材料补充证据；视觉大模型按需补充语义，JEV与主认知复用结果。环境经验只留接口，不实现环境匹配、经验提取或检索。

## 输入和模块汇集

采样入口记录原图引用、来源、拍摄时间与接收时间。`VisionStore`压缩保存图像，按内容校验值复用图像资产，帧记录仍保留各自采样时间。完整ID留在程序，模型侧使用短媒体、轨迹和人物代号。

`VisionService`接受可扩展的`modules`映射。分析模块不要求使用YOLO结果：各自返回结果，独立模块可并行执行；有状态的本地追踪仍由采样线程按顺序维护。模块失败不会吞掉其他结果。模块有需要时可接收frame和observed_at，不能用分析完成时间替代采样时间。

| 来源 | 当前产物 | 含义与限制 |
| --- | --- | --- |
| 本地变化检测 | changed | 默认像素变化基线，不产生物体语义 |
| 可选YOLO＋ByteTrack | class、box、confidence、track | 类别、归一化检测框、检测分数、轨迹；轨迹不证明姓名，检测分数不是身份概率 |
| 可选本地人脸 | faces：face、box、object_id、certainty、score、gap | 匿名面孔参考号、图中区域、人物关联、匹配分数与领先差距；分数不是身份概率，已关联身份仍需结合其他证据 |
| 扩展分析模块 | 模块自行定义的result | 通过统一证据接口添加，不改变已有模块；模块间依赖由宿主明确调度 |
| 按需视觉模型 | description、change_degree、change_reason | 当前可见描述、前后比较等级与依据；单图及首次观察不比较时输出unknown |
| 环境经验接口 | status=not_implemented、references=[] | 仅预留，不查询也不推断旧环境 |

每项模块证据包含module、version、frame、observed_at、completed_at、status、result、error。status明确区分completed、not_run与failed；未运行不能当未检测到对象。原图中的文字不当程序指令。当前描述和当前帧可分别来自不同时间，继续保留description_frame及described_at。

证据保存在对应frame上；过期结果不冒充最新现场。主认知接收相关模块结果与观察时间，JEV输入把模块时间统一转换为相对当前锚点的整数毫秒。不同模块共同引用同一材料，不增加独立证据次数。

## 本地人物参考与自动积累

`LocalFaces`支持OpenCV YuNet检测＋SFace特征匹配；不调用视觉大模型、不自动下载模型。配置启用且模型可用时运行，缺文件标not_run，依赖或运行错误标failed。

不要求用户专门登记。程序自动积累有合适检测质量的匿名面孔参考，按图像内容去重、匹配差异及数量上限筛选。参考号F仅在当前主体的本地面孔库内使用，不是实名，也不保证遮挡或相似外观下始终对应同一人。

主认知参与身份语义：已有明确视觉身份依据时，通过现有embodied动作提供关联；程序核验当前材料确有该面孔、P代号能映射到已有对象，再保存关联。声音归属不单独绑定人脸，不使用主认知的一段自然语言回应自动猜人物。已有关联冲突时，自动路径拒绝改绑，人工补充路径允许纠正。

仅当该功能开启且有视觉材料时，主认知输入附加以下完整说明，主认知照片保存规则不另扩展：

```text
有明确视觉身份依据时，可用embodied动作“关联面孔 F代号 P代号：依据”关联人物参考；声音归属不单独证明脸的身份，无依据不关联。
```

关联动作严格形如`关联面孔 F1 P1：依据`，由程序恢复当前P代号。这个内部关联动作不会作为机器人动作播出。归属可靠后，已积累的参考照进入`PersonPhotos`多照片历史，保留拍摄时间、原帧关联、来源和身份依据；后续新参考自动作为候选保存，不会仅凭一次匹配升级为独立身份确认。人工纠正关联时，旧自动关联照片降为候选，独立人工登记的参考保留。

环境观察页面显示检测到的面孔区域，并可选择已有对象进行人工关联或纠正。自动积累关闭后不新增参考库；已有参考和照片不会因关开关被删除。识别准确率和运行速度仍需真实摄像头材料验证，模拟测试只证明流程行为。

## 主认知原图

JEV1新增`main_image=omit|include`，默认omit，独立于level与recall_memory。新人物、新场景等信息仍应进入主认知；已有观察与模块证据足够时无需原图，细节不足时可include。

程序仍检查`cognition_images`能力开关与原图可用性。`MainImageGate`按图像内容校验值在同一session去重；不同frame但同一图像内容也只提供一次。成功请求后提交记录，失败仍可重试。同一请求内部也去重。不同主体、不同session分开；无session使用本次SubjectProcess实例的上下文。记录不跨进程持久化，不等同于模型保存了原图。

用户明确要求重新看图片时可绕过去重，仍须JEV选择include及模型具备图像能力。原图省略后，文字观察和模块证据仍保留。原图传输使用实际图片数据；短代号只负责关联，不能代替原图。

## 照片进入记忆系统

主认知成功实际接收的照片，按原始frame关联本次输入经历，作为记忆候选；不根据视觉变化等级替主认知提前决定所有候选是否值得记住。重复原图不会创建重复曝光快照。存储容量检查仍生效。

`VisualMemory`随经历提交`MemoryExperience.media`，包含媒体引用、采样时间、独立描述时间及模块证据；原始图像留在媒体存储，不编码为大段文字。记忆后端返回`media_marks`时，按经历段明确选择照片；没有媒体选择接口的旧后端，以其`stored_marks`接受的经历保留关联照片。未完经历或失败保留候选，明确未接受的已结束经历释放该候选长期保留标志。REMS旧端口不支持media字段时继续使用旁路媒体关联，不假称其已经进行了逐照片视觉评估。

主认知不增加复杂的照片保存提示词。人物参考照与经历照片分别管理：前者服务本地匹配及人物资料，后者由记忆系统管理经历关联。

## 刷新与比较

本地采样与大模型频率分开。重要检测/模块变化经过冷却和预算控制后可触发语义更新；稳定场景不会按每次采样重复调用。首次语义观察等待期间，没有其他分析模块时，冷却内的相同帧复用待处理照片，避免数据库反复写入；初次云端尚未完成时不会发布成已完成的语义观察。关闭cloud_enabled后仍可维护本地观察，不请求云端模型。

常规刷新及首次观察只看当前图，模型提示不要求比较，变化等级均标unknown。observe和服务均有无比较材料的程序兜底；初始化通过reason=initial标记，不通过high假称发生变化。描述时间不会因为新本地检测而自动变新。需要解释前后差异时显式调用`compare_images`：同一次请求传当前图及历史图、保留两图时差，检查时间先后和主体隔离，执行相同调用预算。仅此类有历史材料的分支要求比较；材料不足可unknown，取景变化与现场变化分开解释。两张图不能证明采样间隔中发生的过程；当前实现不增加短视频理解模型。

HTTP入口：`POST /api/vision/compare`，传previous_frame、current_frame；`POST /api/vision/associate-face`，传frame、face、object_id。两者要求同源，人物关联检查对象存在及当前材料包含面孔。

## 配置与启用

配置通过`JSHI_VISION_`前缀环境变量读取，修改后重新启动服务生效。

| 配置后缀 | 默认值 | 作用 |
| --- | --- | --- |
| DETECTOR | change | 可选yolo；YOLO依赖及权重需可用 |
| CLOUD_ENABLED | true | false关闭视觉云端观察和比较 |
| JEV_IMAGES | false | 是否给JEV提供实际原图，通常只用整理材料 |
| COGNITION_IMAGES | false | 主认知图像能力开关，确认模型支持图片后才开启；仍受JEV带图选择控制 |
| FACE_ENABLED | false | 可选本地人脸模块 |
| FACE_DETECTOR_MODEL / FACE_RECOGNIZER_MODEL | 空 | 本地YuNet和SFace ONNX文件路径 |
| PORTRAIT_ENABLED | true | 自动积累参考功能，可独立关闭；仅face_enabled时实际运行 |
| PORTRAIT_LIMIT | 8 | 每个匿名面孔最多8个差异参考 |
| FACE_IDENTITY_LIMIT | 128 | 每个主体最多128个匿名面孔记录 |
| FACE_MATCH_THRESHOLD / FACE_MATCH_GAP | 0.50 / 0.08 | 匹配及候选差距参数，需用真实材料校准 |
| FACE_MIN_SIZE | 64 | 检测脸区域的最小像素边长 |
| PORTRAIT_SIMILARITY_LIMIT | 0.95 | 已有参考过于相似时不再增加 |

本地人脸可选依赖为`vision-face`；没有依赖、模型文件或清晰面孔时，不能宣称人脸匹配已完成。此次实现没有启用当前运行实例、下载模型或修改运行数据。
