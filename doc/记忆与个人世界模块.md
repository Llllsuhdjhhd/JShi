# 记忆与个人世界模块

本分支在现有主体流程上补强两个可替换模块，并把它们更完整地接入状态组装链路。

## 记忆模块

`jshi.memory.MemoryPort` 仍保持窄接口：`remember_fact` 与 `recall`。本轮新增：

- `recall` 支持按 `object_id` 过滤，只召回与当前对话对象相关的历史事实。
- 召回评分支持中文单字与相邻二元组，减少中文文本直接按空格分词时无法命中的问题。
- `RecalledFragment` 携带 `object_id`、`source_ids` 和评分，便于后续审计与排序。
- `MemorySource` 优先使用注入的 `MemoryPort`；未注入时保留原有本地事实历史实现。
- CLI 新增 `recall` 命令，可直接查询当前记忆端口。

## 个人世界模块

`jshi.personalworld.PersonalWorldPort` 继续负责为每次活动选择个人世界条目。本轮新增：

- 非约束条目按“重要性优先、查询相关性次之”排序。
- 承诺与主体面未完成现实仍作为常驻约束始终加载。
- 相关性只用于打破同一重要性档位内的并列，不会让单次查询轻易重排主体长期价值。

## 验证

新增与调整的测试覆盖：

- 记忆按对象过滤与中文召回排序。
- 注入的 `MemoryPort` 真正进入状态组装器。
- CLI `recall` 命令走记忆端口。
- 个人世界查询相关性只作为重要性并列时的排序依据。
