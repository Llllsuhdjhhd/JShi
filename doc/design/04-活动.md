# 04 活动（Activity）

> 模块文档。术语以《概念词汇》为准，流程位置见《00 流程总览与输入边界》阶段④。
>
> 状态：初稿，按“活动不挂载事件”重校。

## 1. 定位

活动是一次完整处理过程：从接受触发开始，经过状态组装、认知、行动，到收尾结束。它是工作单元，不是长期事件。

## 2. 活动与事件分离

- 活动：单次处理过程，状态为 open / waiting / completed / abandoned；
- 事件：长期事情，属于 07 / 09 记忆侧；
- 活动不挂载事件，不维护未完成事件。

## 3. 职责

04 只做：

- 建立活动；
- 维护活动状态与状态迁移审计；
- 关联触发来源与活动来源链；
- 完成活动。

04 不做：

- 事件创建 / 完成 / 挂载；
- 认知内容生成；
- 上下文组装；
- 记忆落位。

## 4. 接口

```text
Activity
  subject_id
  kind              # external | internal
  trigger
  status
  intention_ids     # 占位
  id
  created_at
  updated_at
```

`active_concern_ids` 仅作为历史数据库字段兼容保留，不再作为活动事件挂载语义。

## 5. 验收标准

- 外部活动建立、运行、完成；
- 活动状态迁移可审计；
- 活动不挂载事件；
- 活动完成不删除、不影响事件。
