# 04 活动（Activity）

> 模块文档。术语以《概念词汇》为准，流程位置见《00 流程总览与输入边界》阶段④。
>
> 状态：初稿，待讨论定稿。本文只用文字与表格描述契约，不出现实现代码。

## 1. 定位

本模块回答一个问题：**一次活动是什么、怎么开始、怎么结束，以及活动与事件、工作集、意图是什么关系**。

活动是匠石的一次完整处理过程：从接受一个触发（外部输入事实或内部触发）开始，经过组装工作集、认知、行动，到收尾结束。它是**工作单元**，不是长期事情——长期事情由**事件**承担。

## 2. 活动与事件：两个层面的区分

| 层面 | 活动 | 事件 |
|------|------|------|
| 本质 | 一次处理过程（开始 → 结束） | 一件长期事情（未完成 → 完成） |
| 时长 | 单次活动，有明确结束 | 跨多次活动，可长期存在 |
| 状态 | 开放 / 等待 / 完成 / 放弃 | 未完成 / 完成 |
| 管理方 | 本模块（04） | 事件生命周期（07） |
| 关系 | 挂载一个或多个事件 | 可被多次活动挂载（形成推进史） |

关键约定：

- **活动完成 ≠ 事件完成**。活动结束只代表这次处理完毕；事件是否了结由事件生命周期判定（显式完成或超时归档）；
- **活动挂载事件 ≠ 事件属于活动**。挂载表达"本次活动聚焦并推进了哪些事件"，可追溯；
- 一次活动可挂载多个事件；一个事件可被多次活动挂载。

## 3. 职责与边界

### 3.1 04 做什么

- 建立活动：确定主体、种类（外部 / 内部）、触发来源；
- 管理活动状态与状态迁移；
- 管理事件挂载：初始为空，认知后由模型聚焦回填，显式引用可预挂载（未来）；
- 挂接意图系统（占位）；
- 保留活动工作状态（本次活动的输入、已装载材料、追加召回）；
- 记账与审计（建立、挂载、完成等）。

### 3.2 04 不做什么

- 不判断输入归属哪个事件（02 已废弃归属判断；聚焦由认知阶段模型完成）；
- 不完成或创建事件（07 的职责；新事件由认知后显式提议创建）；
- 不产生认知内容（05）、不生成行动文本（06/10）；
- 不决定模型上下文内容（03 组装）与追加召回的执行（05）。

## 4. 生命周期

### 4.1 外部活动

1. **建立**：输入落位（阶段①）后建立活动，触发来源 = 输入事实标识，种类 = 外部，初始挂载为空，状态 = 开放；
2. **运行**：接收 03 组装的工作集 → 认知（05，可追加召回）→ 行动（记录语言行动）；
3. **回填**：认知后模型聚焦的事件标识经程序校验后回填活动挂载；意图系统解析的意图标识回填（占位）；
4. **收尾**：行动记录后活动完成；异常或主动放弃可标记放弃；需要等待外部结果时可标记等待（占位）；
5. 收尾时活动状态迁移写入审计（当前占位，见 §7）。

**结束是外部标记，不是活动自身行为**：活动完成、放弃或等待，都由主流程在收尾阶段显式标记；活动自身只维护状态字段，不会"自动结束"。当前标记时机是行动记录之后；未来接入结果反馈（10）后，完成标记可能延后到外部结果确认。

### 4.2 内部活动

内部活动（反思、记忆整理等）与外部活动同构：触发为内部触发文本，种类 = 内部，不经过对象解析；建立时挂载当前活跃事件（占位）；同样经历运行与收尾。

## 5. 行为规则

1. **初始挂载为空**：新输入到达时不判断归属、不预挂载事件（省模型耗时）；除非输入信封显式携带事件标识（未来）；
2. **认知后回填**：模型输出聚焦的事件标识后，程序校验事件确实存在，回填活动挂载，并记 `activity_events_attached`（依据 = 模型聚焦）；
3. **挂载范围**：回填只接受库中已有事件；不存在的标识忽略并记录；
4. **活动工作状态**：本次活动的工作集、当前理解、追加召回片段属于活动内部状态，活动结束后不保留；需要保留的内容先进入历史，再由后台沉淀；
5. **意图挂接**：活动建立时意图系统挂接（占位）；意图可暂停、继续、完成或放弃，须留原因；本期只保留字段，不填充；
6. **完成不删除**：活动完成后记录保留，事件不受影响；
7. **状态迁移审计**：开放 → 等待 / 完成 / 放弃 的每次迁移应写入审计（当前占位未实现，见 §7）；
8. **内部活动同构**：内部活动不经过对象解析，但建立、运行、收尾与外部活动一致。

## 6. 接口契约（文字描述）

### 6.1 活动的基本信息

| 字段 | 说明 |
|------|------|
| 主体标识 | 哪个匠石 |
| 种类 | 外部（由外部输入触发）/ 内部（由内部触发） |
| 触发来源 | 外部 = 输入事实标识；内部 = 触发文本 |
| 状态 | 开放 / 等待 / 完成 / 放弃 |
| 事件挂载 | 本次聚焦的事件标识集合（认知后回填） |
| 意图标识 | 意图系统解析结果（占位） |
| 时间 | 建立时间与最近更新时间 |

### 6.2 对外能力

- **建立活动**：给定主体、种类、触发，创建一条开放活动；
- **更新活动**：更新状态、事件挂载、意图标识；
- **查询活动**：按主体或状态列出活动，读取单条活动；
- **挂载事件**：认知后回填事件挂载（程序校验存在性）；
- **记录审计**：活动建立、事件挂载、状态迁移均有历史记录。

## 7. 记账与审计

| 记录 | 当前状态 |
|------|----------|
| `activity_created`（活动建立） | 占位（当前直接建活动，未单独记账） |
| `activity_events_attached`（事件挂载回填） | 已实现 |

## 9. 验收标准

- 外部活动：触发指向输入事实，种类正确，建立时挂载为空；
- 认知后模型聚焦：事件挂载回填、存在性校验、记账可追溯；
- 活动完成：不删除活动、不完成或删除所挂载事件；
- 活动与事件标识分离，可区分"哪次活动推进了哪个事件"；
- 意图字段存在且占位可查；
- 内部活动与外部活动同构（建立 → 运行 → 收尾）；
- 状态迁移（开放 → 等待 / 完成 / 放弃）可审计（审计本身为占位，见 §7）。

## 10. 与其他模块的关系

- 依赖：00（输入信封与落位）、01（对象解析）、03（工作集）、05（认知与追加召回）、07（事件本体与完成判定，未来）、08（新事件创建的来源关联）、06（认识状态，认知内容挂活动）；
- 被依赖：10（语言行动记录活动标识）、11（治理与连续性检查活动）、12（反思作为内部活动）、14（活动统计：时长、挂载、成本）。
- 概念边界：活动 ≠ 事件；活动工作状态 ≠ 长期记忆；活动挂载 ≠ 归属判断。

## 11. 扩展性预留

- 多轮活动：同一件事的多轮对话是否归属同一活动，由验证决定；
- 流式输入：流式片段到达时活动如何累积；
- 活动恢复：异常中断后可否继续同一活动；
- 活动与外部结果反馈：等待状态与 10 联动；
- 事件挂载的显式预挂载接口（输入信封携带事件标识）。
