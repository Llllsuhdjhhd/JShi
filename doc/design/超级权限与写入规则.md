# 超级权限与写入规则

## 目标

给某个对话对象（例如 `lux`）授予“超级权限”，带密码。密码登录后，该对象可以在对话中用特殊指令让匠石把内容写入个人世界或提示词。

## 超级权限

- 存储：`{data_dir}/super_permissions.json`，只存加盐哈希，不存明文密码。
- 授予：`python -m jshi.app.cli grant-super <对象名或object_id> --password <密码>`。
- 登录：`talk` 里 `/login <密码>`，成功后本会话获得特权；`/logout` 退出。

## 特权指令（需先登录）

| 指令 | 落点 |
|------|------|
| `/value <内容>` | 个人世界：价值观（会进提示词【价值】） |
| `/boundary <内容>` | 个人世界：边界（会进提示词【边界】） |
| `/commitment <内容>` | 个人世界：承诺（会进提示词【承诺】） |
| `/rule <内容>` | 提示词：【附加规则】区块（不改长期个人世界） |
| `/rule <区块名> <内容>` | 提示词：【附加规则】区块，带区块标注 |

## 写入规则（落点）

1. 影响“长期自我 / 约束”的内容写个人世界：
   - 价值观 → `/value`
   - 边界 → `/boundary`
   - 承诺 → `/commitment`

   这些会长期保存，并按其装载规则进入提示词的【价值】【边界】【承诺】。

2. 只作为“当前行为规则、不改长期自我”的内容写提示词：
   - `/rule` 写入【附加规则】区块；
   - 可选指定区块名，渲染成 `[区块名] 内容`，供模型知道它属于哪个提示词部分。
