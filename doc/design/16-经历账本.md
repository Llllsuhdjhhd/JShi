# 16 经历账本

> 模块文档。术语以《概念词汇》为准。
>
> 状态：初稿。`ContextViewState` 已落地；`build_memory_batch` 仍暂留在账本供 30 调用。

## 1. 定位

16 保存原始经历，并维护当前 `ContextViewState`。

它只负责：

- 追加经历；
- 保存原文与来源；
- 维护当前 `ContextViewState`；
- 提供经历片段给其他模块。

它不负责：

- 决定模型看哪些经历；
- 决定哪些经历进入记忆；
- 判断事件边界；
- 创建对象；
- 封存记忆。

## 2. 核心概念

### 2.1 ExperienceSegment

```text
ExperienceSegment
  segment_id
  sequence
  subject_id
  actor_kind              # external | subject | system
  output_kind             # external_input | subject_reply | subject_state | subject_silent | internal
  actor_object_id
  mentioned_object_ids
  text_raw
  state_delta
  response_plan
  source_ids
  occurred_at
  status
```

### 2.2 上下文状态

16 维护的不是“每次都从原始经历重新截取”，而是一份持续编辑的上下文状态。

```text
ContextViewState
  version
  context_text
  segment_refs
  excluded_sentence_refs
  focused_refs
  last_applied_sequence
```

更新方式：

- 新经历追加后，进入待合并状态；
- 05 给出 `need_trim` / `need_focus` 意见；
- 16 根据意见增量更新 `ContextViewState`；
- 例如：删除第 2 句、第 98 句；保留第 12 段；聚焦第 30 段；
- 下一次活动继续在当前视图上调整。

### 2.3 记忆游标

记忆游标只属于 30，不放在 16。

```text
30.memory_start
```

30 根据游标区分哪些经历已经投递给 09，避免重复投递。

### 2.4 对象来源

```text
MemoryBatch.object_sources
{
  "OBJ-A": ["segment-1", "segment-3"]
}
```

对象来源必须随经历段流转，09 不得另建对象体系。

## 3. 与 02 / 05 / 30 的关系

```text
16 ExperienceLedger
  -> 保存原始经历
  -> 维护当前 ContextViewState

02
  -> 从 16 读取当前 ContextViewState
  -> 交给 03

05
  -> 提出 context_assessment
  -> 16 根据意见更新 ContextViewState

30
  -> 只读新增经历
  -> 使用自己的 memory_start
  -> 构造 MemoryBatch
```

规则：

- 16 始终保留原始经历；
- 05 的缩减/聚焦意见只更新 `ContextViewState`；
- 更新在正常回复之后应用，不在补充记忆时裁剪；
- 30 用游标避免重复投递；
- 记忆投递不影响 `ContextViewState`。

注意：`build_memory_batch`、`memory_start` 和投递台账属于 30，不属于 16。

## 6. 行为规则

1. 经历只追加，不改写；
2. 原始文本永不删除；
3. 对象 id 只透传 01；
4. 上下文管理只改变 `ContextViewState`，不改原始经历；
5. 记忆投递不改变经历账本；
6. 30 的游标推进必须是显式确认后的行为；
7. 归档只标记，不物理删除。

## 7. 记录、评价与参数

- 记录：`experience_segment_appended`；
- 评价：经历段覆盖率、上下文引用率、记忆投递滞后、游标安全距离；
- 参数：`active_window_chars`。`memory_batch_chars` / `memory_batch_segments` / `memory_batch_max_age` 属于 30。

## 8. 验收标准

- 16 维护 `ContextViewState`；
- 16 不执行记忆封存；
- 16 不创建对象；
- 原始经历不因上下文裁剪而丢失；
- 上下文调整只影响 16 的 `ContextViewState`；
- 30 不重复投递同一段经历；
- 对象来源链可追溯。
