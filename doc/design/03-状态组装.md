# 03 状态组装

> 模块文档。术语以《概念词汇》为准，流程位置见《00 流程总览与输入边界》阶段③。
>
> 状态：定稿骨架（D-009 回写：08 不因现场已有叙述而跳过；记召回触发流水）。03 只编排，检索规则留在各源模块；对接字段以各源已公布端口为准，03 不另造一套。

## 1. 定位

本模块回答：**一次活动进模型之前，匠石以什么状态面对这条输入**。

本轮工作现场 = 既往视图 + 本轮输入。03 把已经存在的材料编排成工作集，不生成上下文，不重切经历，不调用模型，不写长期个人世界。

03 实现的是**适配器**：调用各模块已公布的只读端口，把返回值译成统一片段。它不实现 01 的解析、02 的读取、08 的取量、09 的检索。活跃区是风格化现场正文，不再带 `personal:{id}`；08 每轮仍装真源，供 05 按风格重写，03 不因「现场里已经写过承诺」而跳过。

本轮原话是**当前刺激**，不是装载源。它随工作集的 `input_text` 交给 05，不译成分片，以免与模型请求里的输入重复。

## 2. 谁在什么时候交给 03

阶段③ 开始时，编排层已经做完 ①②。03 不再解析对象、不再读 16。

```text
编排层已有
  subject_id
  input_text                          # 本轮刺激
  SpeakerCandidate                    # ① 的 01 输出，不再 resolve
  ContextViewState                    # ② 的 02 输出，不再 load

03 再查阅（只读）
  主体身份档案                         # 身份系统，不是 01
  08 select                           # 个人世界
  09 recall                           # 记忆线索，最低档
```

统一入口：

```text
AssemblyContext
  subject_id
  input_text
  speaker                             # object_id, label, aliases, status
  context_view                        # 02 交出的既往窗口
  recall_level                        # 初始装载用最低档，默认 1
```

不再使用 `active_zone` 别名，不再让各源看见互不相关的死字段。现场正文由 05 整份重写、16 保存，影响下一轮 02。

## 3. 与各源的对接

各源共用交出物形状，**入参与语义以源模块为准**。片段 id 必须带源前缀，去重只在同一源内按 id；禁止跨源靠裸 UUID 互删。

```text
AssemblyFragment
  source                              # identity | object | activity | personal | memory
  id                                  # 带前缀，见下表
  content
  kind
  status
  importance
  source_ids
  always                              # 常驻：不可被 03 预算丢掉
```

注册表只含下表五源。06 不向 03 提供认识状态，**不注册认识状态源**。

### 3.1 主体身份源 — 身份系统（档案 · 叙事）

不是 01。01 回答「对方是谁」；本源回答「匠石是谁」。

| 项 | 约定 |
|----|------|
| 源模块 | 身份系统 `IdentityProfile`（名、来源、叙事） |
| 03 调用 | `identities.get(subject_id)`，不调 01 `resolve` |
| 03 使用字段 | 名、来源 → `kind=identity_summary`；叙事 → `kind=stance` |
| 片段 id | `identity:{subject_id}`、`stance:{subject_id}` |
| 常驻 | 是 |
| 空 | 主体档案缺失视为编排错误，不是空视图 |

### 3.2 对象源 — 01

| 项 | 约定 |
|----|------|
| 源模块 | 01。入参是已经过门禁的 `SpeakerCandidate`，**禁止在 03 再解析** |
| 03 使用字段 | `object_id`（关联键）、`label`（非空）、`aliases`（字段必有，可空列表）、`status` |
| 片段 id | `object:{object_id}` |
| 常驻 | 是 |
| 内容 | 人读摘要，必须同时含名字与称呼，不得只放 id。aliases 空则摘要里仍保留该字段（空列表），不假装没有称呼这个槽 |
| 过滤键 | 下游 09 仍只用 `object_id`；工作集与进模型必须带 label / aliases（01 §1、§5.2） |

`ModelRequest` 是否单列说话人字段属 05；03 必须先把这三件套放进工作集，05 才能对齐。

### 3.3 活动窗口源 — 02 / 16

| 项 | 约定 |
|----|------|
| 源模块 | 02 已读出的 `ContextViewState`；03 **不**调用 `ActiveZonePort.load` |
| 03 使用字段 | `context_text`、`version`、`style_pack_id` |
| 片段 id | `context-v{version}` |
| 常驻 | 视图正文不占 03 额外条数预算；长度由 16 承担，03 不二次截 |
| 空 | 初次或复位后空视图合法：不生成假片段，本轮原话仍走 `input_text` |
| 不含 | 本轮待合并原文 |

工作集同时保留 `context_view` 对象（供 05 引用版本）和可选的 activity 分片（供模型阅读上一份现场正文）。正文为空则可以没有 activity 分片，但 `context_view` 仍在。

### 3.4 个人世界源 — 08

| 项 | 约定 |
|----|------|
| 源模块 | 08 `PersonalWorldPort.select(subject_id, *, load_level="中")` |
| query | 占位，03 可不传；08 不按本轮输入排序 |
| 预算 | **由 08 按等级取量**。常驻约束由子模块声明、08 合并后保证在场。03 不得再按「额外 4 条」把常驻项砍掉 |
| 03 使用字段 | `id`、`kind`、`content`、`status`、`level`、`entry_type`、`source_ids`、importance / binding 元数据 |
| 片段 id | `personal:{item.id}` |
| 常驻 | 承诺、binding 边界：`always=true` |
| 不装 | 已废除种类（旧数据 `concern`）不进入装载；08 与仓库层过滤，03 不另做 |
| 去重 | 不做与活跃区的 id 去重。现场是风格化正文，不能证明 08 真源已装入；每轮仍交 08 选出的条目，供 05 按实质重写 |
| 跳过 | 08 内部未入选的项由 08 负责；03 只记录自己因去重或全局上限跳过的 personal 片段 |

03 不调用 08 的写入接口，不升格价值 / 关系 / 能力。03 不调用 100 的 `select_values` 再装一遍。

### 3.5 记忆源 — 09

| 项 | 约定 |
|----|------|
| 源模块 | 09 `MemoryPort.recall(subject_id, query, *, object_id, level, limit, anchor_event_ids)` |
| query | `input_text`。既往视图**不是**记忆查询基准（09 §7） |
| object_id | ① 的说话人 `object_id`，无则本源返回空 |
| level | 初始装载最低档（默认 1）。档位语义由 09 解释，03 不把档位换算成条数 |
| 03 使用字段 | `event_id`、`text`、`kind`、`object_id`、`source_ids` |
| 片段 id | `memory:{event_id}` |
| 常驻 | 否 |
| 名字 | 09 过滤键仍是 `object_id`。记忆片段文本即原文（含名字），展示名由 03 用 01 档案 join（label / aliases），不要求 09 改召回结构 |
| 边界 | 初始装载是本轮 05 能看见的唯一 09 来源。05 不同轮补召回。档位读 09 策略快照（默认最低档）。缺口记入打分，开口后或下一拍再取，不回写本轮 03 注册表 |

03 不调用 `ingest` / `consolidate` / `dream`。

## 4. 组装器行为

1. 按注册顺序调用各源 `load(AssemblyContext)`；
2. 源内按带前缀的 id 去重，保留先出现者；
3. 按**三档**分配**工作集全局上限**（`working_set_limit` = **1500 字**，魔法书 `src/jshi/core/params.py`，占位、由 14 调；不随窗口放大，不管活跃区）：
   - `protected`：永不裁、不占预算 —— 身份 / 对象 / 既往视图正文 / 08 常驻（`always=true`）；
   - `memory`：单独一档，「受预算但仍可被裁」—— 占用同一上限，但在普通条目之前先分配，背景不会把它挤掉；memory 自身超限时仍会被裁；
   - `ordinary`：普通条目（个人世界普通价值等）—— 最低档，预算不足时**先裁**。
   被裁片段计入对应源的 `skipped_ids`；除 03 自身因预算跳过的片段外，源内部的筛选仍在各源。
4. 生成 `SubjectState` 快照与工作集；
5. 汇总装载报告（每源：实现状态、装入 id、跳过 id、错误）；
6. 单源失败只记入该源报告，其余源继续；
7. 编排层记账 `current_state_assembled`。

快照与分片分工：

- `SubjectState`：稳定自我与约束摘要（身份、立场、已装入的价值与承诺）。不是把全部分片再抄一遍。
- `fragments`：进模型的可核对背景（含对象摘要、既往窗口正文、个人世界条目、记忆线索）。
- `input_text`：本轮刺激，单独一路。
- `speaker`：01 三件套，供 05 对齐，不埋进某一条分片里才算有。

主体面未完成现实 / `concern` 已废除（D-007）：`SubjectState` 不携带该字段，也不从 08 回填。

## 5. 输出

```text
AssembledWorkingSet
  input_text              # 本轮刺激，必有
  speaker                 # object_id, label, aliases, status
  subject_state
  fragments
  context_view            # 02 的对象，可为空视图
  report
```

经历段引用以 `context_view.segment_refs` 为准。

## 6. 记录、评价与参数

- 记录：`current_state_assembled`（各源 status、loaded_ids、skipped_ids、错误；说话人 object_id / label；视图 version）；
- 评价：来源覆盖、跳过率、记忆线索引用率，由 14 统计；
- 参数：初始回忆档位（默认最低）；工作集全局上限 `working_set_limit` = **1500 字**（魔法书，软约束，由 14 调；只卡本轮回忆 + 普通价值）。活跃区长度 = 窗口 × 1/30（16）。普通价值字符预算 = 活跃区 × 1/5（100 / 08）。窗口默认 100 万 token。

## 7. 验收标准

- 03 不调用模型，不重切 16 原文，不写长期个人世界；
- 工作集必有 `input_text`；空 `context_view` 合法；
- 对象材料含 `object_id`、`label`、`aliases`，不只含 id；
- 身份源不调用 01 `resolve`；对象源不第二次解析；
- 活动窗口源不调用 02 `load`；
- 08 / 09 的筛选与检索规则不在 03 内复制；
- 无认识状态源；
- 单源失败不影响其他源；装载报告可追溯。

## 8. 与其他模块的关系

- 依赖：身份系统、01、02、08、09（只读已公布端口）；
- 被依赖：04（活动带着这次快照）、05（刺激 + 快照 + 分片 + 说话人）；
- 概念边界：工作集 ≠ 长期记忆；快照 ≠ 身份本身；初始装载 ≠ 同轮补召回（后者已取消）；主体身份 ≠ 说话人对象。

当前实现与本文对齐：五源注册；对象源装说话人三件套；`AssemblyContext` 带 speaker，无 `active_zone` 别名；认识状态源已移除；08 常驻不再被 03 按条数二次截断。`ModelRequest` 说话人字段仍归 05。
