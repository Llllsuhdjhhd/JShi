# 03 状态组装

> 模块文档。术语以《概念词汇》为准，流程位置见《00 流程总览与输入边界》阶段③。
>
> 状态：初稿，按“活动窗口替代事件源”重校。

## 1. 定位

本模块回答：**一次活动进模型之前，匠石以什么状态面对这条输入**。

03 只做组装编排：收集身份、活动窗口、个人世界、记忆、认识状态、对象信息等已有内容，合并成工作集与主体状态快照。它不实现任何装载逻辑。

## 2. 装载源

| 源 | 装载内容 | 实现方 |
|----|----------|--------|
| 身份源 | 身份档案、叙事、当前立场 | 01 |
| 活动窗口源 | 02 输出的原始经历段 | 02 / 16 |
| 个人世界源 | 价值、承诺、关系、能力等 | 08 |
| 记忆源 | 历史事实线索召回 | 09 |
| 认识状态源 | 已接受 / 暂定认知背景 | 06 |
| 对象源 | 说话人对象档案摘要 | 01 |

事件、未完成事件不在 03 装载。事件只属于 07 / 09。

## 3. 组装器行为

1. 调用各装载源；
2. 合并去重；
3. 预算截断；
4. 生成主体状态快照与工作集；
5. 汇总装载报告；
6. 记账 `current_state_assembled`。

活动窗口源已由 02 控制长度，03 不再对经历段做二次预算截断。

## 4. 输出

```text
AssembledWorkingSet
  subject_state
  fragments
  active_zone
  active_segment_ids
  report
```

`SubjectState.concerns` 暂不由活跃区产生，待 07/09 记忆侧提供事件状态后再接回。

## 5. 验收标准

- 03 不调用模型；
- 03 只读已有记录；
- 活动窗口来自 02，不含事件；
- 个人世界、记忆等来源按预算装载；
- 单源失败不影响其他源；
- 装载报告可追溯。

## 6. 与其他模块的关系

- 依赖：01、02、08、09、06（未来）、01 对象源（未来）；
- 被依赖：04、05；
- 概念边界：工作集 ≠ 长期记忆；快照 ≠ 身份本身；初始装载 ≠ 追加召回。
