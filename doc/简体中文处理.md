# 简体中文工作内容

统一范围：新文字输入、ASR转写的工作文本、主认知/JEV/工具/自省的自然语言正文、视觉描述、记忆正文、摘要、人物肖像与工作缓存。保留英文及其他语言；不改标识符、引用、网址、代码、工具参数和原始诊断返回。

JShi使用`jshi.simplified`；REMS使用相同规则的`rems.utils.simplified_text`。转换发生在入口、模型输出解析和写入边界，不在每条检索候选上执行。查询只在进入召回时处理一次；候选匹配仅做小写和必要字符筛选。

发生文字转换时，JShi的原始输入写入`original_text_evidence`历史，REMS输入及工作字段的原始值写入`simplified_originals`。记忆模型输出因转换而发生变化时，将原始返回另存到数据库旁的`simplified-model-originals.jsonl`。模型原始JSON仍用于格式、Schema验证和故障诊断，不直接对原始JSON字符串做替换。

## 迁移

先预览：`python -m jshi.app.simplified_migration --data-dir .jshi`。

执行：`python -m jshi.app.simplified_migration --data-dir .jshi --apply`。仅修改白名单内的工作字段，先备份SQLite与实际改变的工作JSON，另存字段原始值；不重写历史模型请求、原始录音或日志。备份放在`.jshi/backups/simplified-年月日-时分秒/`。重复执行无变化时不产生重复修改。

当前SQLite全文索引由原有触发器随正文更新。变更事件写入`.jshi/rems/simplified-reindex.json`；重新启动语音服务时，使用该进程唯一的Qdrant客户端和本地已缓存嵌入模型，更新这些事件及引用它们的索引。全部成功后删除清单，失败则保留并可重试。不会因迁移额外调用付费模型，不会覆盖其他版本的向量集合。

运行中的旧服务仍持有旧代码与内存缓存，需要重启使简体规则和索引更新生效。不要在旧服务占用Qdrant时启动第二个实例。

## 验证

覆盖繁体输入转简体、自然语言输出、原始证据保留、人物ID与引用、工具参数保护、迁移备份与幂等、检索不再转换候选，以及入口、主认知和视觉回归。简繁统一只解决文字处理开销，不修复模型额度不足、JSON格式错误或所有排队延迟。
