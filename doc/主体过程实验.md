# 主体过程实验

## 1. 实验目的

当前实现不以“已经创造一个人”为结论，而验证最小主体闭环：

> 匠石能否把认知、选择、行动和结果持续归属于自己，并让这些经历真实影响后续活动。

总体概念见[《匠石总体图景》](总体架构.md)。

## 2. 已实现对象

### 个人内容

用于保存记忆、价值、关系、承诺、关切、能力、审美和自我理解。每项内容具有来源、状态、修订版本和时间。

### 当前活动

用于保存一次外部活动或内在活动的触发原因、活跃关切、意图和完成状态。一次活动不等同于一个永久记忆。

### 认知内容

用于保存感知、回忆、推断、想象、评价和意图，并区分其认识状态和证据来源。

### 状态变化

用于记录认知内容或个人内容为何从一个状态转为另一个状态。旧状态及变化理由不会被最终状态覆盖。

### 两种历史

- 事实历史保存输入、语言行动和外部结果；
- 主体历史保存认知出现、认识状态变化、反思及个人内容变化。

## 3. 当前主体循环

外部活动目前按以下方式运行：

1. 记录完整文字输入；
2. 建立当前活动；
3. 将输入记录为已感知的他人报告；
4. 读取活跃的个人内容；
5. 使用基础认知模型形成认知内容；
6. 将认知内容初始标记为“考虑中”；
7. 记录语言行动；
8. 保存事实历史和主体历史；
9. 完成当前活动。

反思活动会读取近期两种历史和活跃个人内容，调用同一认知基础形成一项“考虑中”的评价。反思结果不会自动改写长期人格。

## 4. 当前可验证行为

- 一个想法可以从考虑中转为暂时接受、接受、拒绝、搁置或修正；
- 每次状态变化保留理由；
- 关切和承诺可以跨活动持续；
- 关切或承诺的完成和解除必须显式记录；
- 使用相同模型但拥有不同个人内容的匠石，可以形成可追溯的不同认知结果；
- 内在反思与外部事实分开保存。

## 5. 使用方式

在项目根目录设置 Python 路径：

```powershell
$env:PYTHONPATH="src"
```

创建一个基础型匠石：

```powershell
python -m jshi.app.cli create stone
```

添加关切或承诺：

```powershell
python -m jshi.app.cli add-personal stone concern "继续理解朋友最近的疲倦"
python -m jshi.app.cli add-personal stone commitment "下次继续询问他的近况"
```

进行一次外部活动：

```powershell
python -m jshi.app.cli experience stone "今天有些疲倦"
```

进行一次内部反思：

```powershell
python -m jshi.app.cli reflect stone "回顾刚才的交流"
```

查看个人世界和历史：

```powershell
python -m jshi.app.cli personal stone
python -m jshi.app.cli history stone
python -m jshi.app.cli history stone --kind fact
python -m jshi.app.cli history stone --kind subject
```

将一项认知转为暂时接受：

```powershell
python -m jshi.app.cli transition <认知标识> provisional "目前证据有限，先暂时接受"
```

## 6. 模型配置

没有配置远程模型时，程序使用离线测试模型，只用于验证框架。

使用兼容 OpenAI 对话接口的模型时，可以设置：

```powershell
$env:JSHI_MODEL_ENDPOINT="接口地址"
$env:JSHI_MODEL_API_KEY="密钥"
$env:JSHI_MODEL_NAME="模型名称"
```

在项目概念中，该模型提供匠石的内生认知基础；接口部署位置不决定主体归属。

## 7. 当前限制

- 个人内容检索暂时采用透明的简单选择，没有实现成熟的注意机制；
- 模型输出整体记录为一项认知内容，尚未自动拆分多项推断、评价和意图；
- 认识状态主要由明确操作改变，尚未实现可靠的自动变化原则；
- 反思不会自动形成长期记忆、能力或价值变化；
- 尚未实现外部行动结果的自动反馈；
- 尚未实现持续输入、多模态、实时认知和模型迁移；
- 当前实验只能验证可观察的主体连续关系，不能证明主观意识。

这些限制属于后续实验问题，不应通过未经验证的自动规则过早填补。
