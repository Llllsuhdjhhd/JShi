## 条目

### I-001 单次模型响应的多用途消费（流式分段）

- 状态：开放
- 提出：2026-08-14

一次大模型生成（一个输入、一次响应流）可以同时解决多个问题，例如：

- 对本次事件的回应（行动文本）；
- 对象确认（说话人是否真是档案中的对象）；
- 事件是否结束（显式完成 / 放下 / 替代）；
- 事件的重要性（用于个人世界与活跃区排序）；
- 上下文管理（活跃区调整：聚焦、剔除、召回等）。

响应按"用途段"组织：某一阶段只等到自己那部分回应就可以继续，剩余部分留给后续阶段使用；不必每个问题各调用一次模型，也不必等完整响应。

与现状的衔接：`ModelResponse` 已预留 `text` / `recall_requests` / `object_assessment` / `focused_event_ids` 等结构化字段；活跃区的模型筛选（02 未来项）与事件完成/重要性判定可走同一响应。流式分段消费依赖模型输出协议稳定，具体字段与解析归 05 认知文档细化。

注意：单次响应多用途会减少调用次数，但增加结构化解析、校验与失败隔离的要求；每段输出仍是候选结果，须遵守来源与认识状态约束。
