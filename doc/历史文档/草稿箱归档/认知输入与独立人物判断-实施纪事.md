# 认知输入边界与独立人物判断

- 状态：已完成
- 开始日期：2026-10-05
- 代码：subject/process.py、models/prompt.py、skill/cognition.py、app/voice.py、voice/person_review.py、voice/jev.py
- 测试：test_person_review_split.py、test_voice_main_review.py及原主流程/语音回归

## 用户决定

1. 主认知输入只来自信封本批新发言，不能把以往录音再次拼入。本轮以外的交往由片场和待整理事件延续。
2. 人物判断独立提示词、独立路径，使用更充分的背景，下一轮给入口建议；快速JEV不承担慢判断。
3. 名称统一为JEV。独立结果可影响后续JEV，JEV结合当下证据作输入归属收口。
4. 最近成功片场加未整理输入与匠石回应、写场失败合批重写的决定保留。

本次替代已归档讨论中的“⑤同时人物复判”和“旧背景重新作为入口输入”两项；没有改成自动登记档案，也没有改变人工选择旧输入关联的规则。

## 助手实施意见（工程取舍）

独立核对单线程、最多8批、2分钟有效期、最多6位候选；这些是保守的可调工程限制，不代表用户指定或已验证最优。候选资料不证明当前说话人，物理声音结论仍由声纹模块提供。返回按input_id/N/P对位，不回写已处理轮次；结果完成时间必须早于下一批输入收到时间。晚到人工关联优先。

## 代码原状与改动

原来认知提示词和Schema同时要求人物结论，app回调储存主流程短评；语音入口缓存旧背景并附到后续input_text。现已拆除：主认知保留回应对象选择，独立流程负责人物建议；入口观察按input_id入待整理片场。新建PersonReviewer并配置专用模型端口。测试发现当前输入可能被记忆源再次召回，按事实来源编号过滤重复；旧信封旁注也不成为输入事实。

## 调试记录

针对输入边界、延迟核对、失败、越界、人工关联时序、JEV后续反馈、旧录音不重复输入的52项相关测试已通过。全量回归727通过、1跳过，剩余4项是原有参数覆盖/工具提示措辞失败。最后针对提示词、人物权限、输入边界与JEV反馈的67项回归全部通过；源码编译及diff检查通过。

## 验收与遗留项

独立判断不产生回复、动作、工具、正式声纹登记或人物档案修改。真实麦克风准确率和耗时尚未实测；没有重启运行中的服务，没有修改真实.jshi资料。当前文档已同步，实施纪事归档到doc/历史文档/草稿箱归档。
