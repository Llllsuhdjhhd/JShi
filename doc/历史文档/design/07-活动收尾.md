# 07 活动收尾

> 模块文档。术语以《概念词汇》为准，流程位置见《00 流程总览与输入边界》阶段⑦。
>
> 状态：定稿。07 只关闭本轮活动并审计。记忆投递归 30。事件不在本模块。

## 1. 定位

07 只负责**一次活动的收尾**：把活动标为结束，留下状态迁移审计，并告诉编排层「本活动已经结束，30 可以尝试投递」。

主链路一律关闭为 `completed`。`response_plan.mode` 为 `respond` / `think` / `ignore` / `wait` 均如此。`wait` 是 06 的回复方式，不是活动状态，也不把同一条活动挂起。

下一轮外部输入创建新活动。连续性靠 16 保存的活跃区与历史，不靠未关闭的活动。

## 2. 职责

### 2.1 07 做什么

- 接收已标记的回复状态（`final_response_statuses`）和可选的行动 id；
- 把活动从 `open` 标为 `completed`；
- 写入状态迁移与 `activity_completed` 审计；
- 返回是否应交给 30（`handoff_to_memory_control`）。07 自己不调用 30、不构造批次。

### 2.2 07 不做什么

- 不生成回复，不校验 `response_plan`（那是 05 / 06）；
- 不根据 `wait` 把活动停在等待；
- 不写经历段，不读取、不改写活跃区（16 已在 10 之后按方案编好）；
- 不构造 `MemoryBatch`，不调用 09，不推进 `memory_start`，不处理记忆失败重试；
- 不创建、不封存、不判断事件（事件只在 09 内部；I-001 的事件完成段不纳入）；
- 不改个人世界，不跑反思。

`abandoned` 仍是 04 的占位状态。本期主链路不用；07 接口也不根据回复方式改走放弃。

## 3. 接口

```text
ActivityClosePort.close(
    subject_id,
    activity_id,
    *,
    final_response_statuses,
    action_id,
    reason,
) -> ActivityCloseResult

ActivityCloseResult
  activity_id
  final_activity_status   # 主链路为 completed
  transition_id           # 本次 open → completed 的迁移；已关闭则为已有记录
  handoff_to_memory_control
```

- 首次关闭：`final_activity_status=completed`，`handoff_to_memory_control=True`。
- 活动已是 `completed` 或 `abandoned`：不再改写、不重复审计，`handoff_to_memory_control=False`。
- 编排层（当前是 `SubjectProcess`）在外部主链路看到 handoff 为真时调用 30 `run_async`。07 不内嵌记忆逻辑。

## 4. 与 04 / 06 / 16 / 30 的关系

- 04 建立活动并保存字段；关闭由 07 执行。
- 06 只标记回复状态，不关闭活动。
- 16 在收尾前已按 05 方案编好新活跃区；07 不回头改账本。
- 30 在 07 确认结束后决定是否投递；批次须分型（债务仍在 30）。

内部活动（如反思）同样经 07 关闭，不另写一套关闭路径。内部入口是否调用 30，由编排层决定；07 不因此改写记忆策略。

## 5. 记录、评价与参数

- 记录：`activity_completed`；`open → completed` 的 `StateTransition`；
- 评价：活动是否关闭、关闭是否可追溯（14 旁路）；
- 参数：本期无。超时归档、放弃入口若以后要做，须改 04 并写决策记录。

## 6. 验收标准

- `wait` / `think` / `ignore` / `respond` 关闭后活动均为 `completed`，下一轮是新活动；
- 状态迁移与 `activity_completed` 可审计，回复状态可追溯；
- 07 不写经历、不改活跃区、不包含记忆逻辑；
- 收尾后编排层能凭 handoff 调用 30；07 失败不得被记忆失败拖成活动未关闭（30 失败不影响 `completed`）。

- `wait` 是否改为同一活动挂起再恢复（须先改 04，本期不采用）；
- 内部活动关闭后是否也尝试投递（当前主链路仅外部入口调用 30）。
