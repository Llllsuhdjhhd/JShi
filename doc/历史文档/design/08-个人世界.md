# 08 个人世界

> 模块文档。术语以《概念词汇》为准，流程位置见《00 流程总览与输入边界》阶段③ 的个人世界源。
>
> 状态：定稿。08 是 100 及后续子模块的薄壳：统一条目外形、合并有序列表、按 id 去重、按等级取量。不决定条目如何排序，不决定条目如何产生。

## 1. 定位

个人世界使不同匠石在相同基础认知下仍有差异。它不是一个仓库，而是一组相互独立的长期内容系统。

08 只做统筹：

- 规定统一条目外形，供 03 装载；
- 向已注册子模块收取**已经排好序**的列表；
- 跨子模块按条目 id 去重；
- 按等级取量后交给 03。

08 不做：

- 不决定「装哪些」——取哪几条只看各子模块排出的前缀；
- 不按本轮输入做情境匹配，不调模型；带模型的装载只占位；
- 不规定条目如何产生、整理、加锁、升格（全部在各子模块）；
- 不保管记忆原文，不召回（09 与 08 平行，不是 08 的子模块）；
- 不处理事件，不装载 `concern`。`concern` 已过时，不迁到 07。

正常活动只读取已有条目，不无声改写长期个人世界（00 稳定原则第 5 条）。05 按风格重写活跃区里的承诺叙述，不等于写入 08。

## 3. 统一条目

各子模块交出的条目，08 只认这些字段：

| 字段 | 含义 |
|------|------|
| `id` | 条目标识 |
| `subject_id` | 所属匠石 |
| `kind` | 来自哪个子系统（value / commitment / …） |
| `content` | 正文 |
| `level` | 低 / 中 / 高。缺省「中」 |
| `entry_type` | 类型，本期阙如占位，08 不解释枚举 |
| `status` | 活动状态 |
| `source_ids` | 来源链 |
| `metadata` | 子模块私有字段 |
| `revision` / `created_at` / `updated_at` | 版本与时间 |

`kind` 标明子系统；`entry_type` 是跨子系统的类型占位，二者不是同一字段。

## 4. 接口

```text
PersonalWorldPort.select(subject_id, query="", *, load_level="中")
    -> 常驻条目 + 按等级取量后的普通条目

PersonalWorldPort.standing_constraints(subject_id)
    -> 各子模块声明的常驻约束，已去重

PersonalWorldPort.select_boundaries(subject_id)
    -> 透传 100 的不可越过边界
```

`query` 保留为占位，本期忽略。`load_level` 为低 / 中 / 高，只影响取量。

子模块向 08 提供：

```text
list_standing(subject_id) -> 该模块的常驻条目（已排序）
list_ordered(subject_id)  -> 该模块可装载的普通条目（已排序，不截断）
```

排序原则由各子模块自己定。08 不重排、不打分。

## 5. 合并、去重、取量

1. 按注册顺序收取各模块的常驻列表，按 id 去重，全部装入。常驻由子模块声明（例如 100 的不可越过边界、承诺），08 不判定「什么算常驻」。
2. 按同一顺序收取普通有序列表；已在常驻中出现的 id 丢弃。
3. 按 `load_level` 对**非价值**的普通条目取量。条目自身的 `level` 分档计数：低档少取，中、高依次增多。普通价值已由 100 按活跃区字符 × 1/5 截断，08 不再用等级额度裁它们。扫描顺序保持各模块交出的顺序。
4. `concern` 即使被某适配器交出，08 也丢弃。

08 只保证跨子模块不重复。**03 不做与活跃区的 id 去重**：现场是风格化正文，不能证明 08 真源已装入；每轮仍装 08 选出的真源，供 05 按实质重写。

## 6. 记录、评价与参数

- 记录：装入 id、因去重或取量跳过的 id、所用 `load_level`；
- 评价：跳过率、常驻是否在场、子模块失败率（14 旁路）；
- 参数：`load_level` 各档取量（占位）。情境匹配 / 模型装载未启用，无对应参数。

## 7. 验收标准

- 03 只通过 08 收取个人世界，不分别调用 100 的预算接口再装一遍；
- 同一 id 不会因多个子模块或常驻+普通而被装两次；
- `concern` 不进入装载结果；
- `load_level=低` 时，其余普通条目（承诺以外的占位种类）明显少于中、高；普通价值条数由字符预算决定，不随 load_level 再砍；
- 08 不按 `query` 改变顺序；
- 正常活动不经 08 写入或升格长期条目。
