# 提示词风格与活跃区全改（coding）

对应设计：`doc/design/提示词风格与活跃区全改.md`（D-009 / I-015）。本次直接编码。

## 1. 目标与范围

最小可跑：

- 材料层不变：`text_raw` 只追加、09 仍用本轮 `input_text` 召回、30 仍只收新输入/新口头。
- 现场层：05 交整份 `rewritten_context`；16 保存正文；空则保留上一份。
- 风格包：可注册；内置木头（默认）/ 苏西坡 / 斯密斯占名。每包 `instruction_first` / `instruction_continue` 两槽，程序按空现场或换包选首次。写法正文另议，槽位先空。配置名不进提示词。选中随主体保存，硬切。
- 召回触发流水：匠石侧 jsonl，不进 09。
- 本轮不打 `memory_ratings`（模型可不填；有则仍可入库，不作为本方案验收）。
- 03 不再因活跃区 id 跳过 08。

不做：按风格各存活跃区、内部活动套风格包、改 09 后端、有效性分析本轮推进。
