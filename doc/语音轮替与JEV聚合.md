# 语音轮替与JEV聚合

最近更新时间：2026-10-12 21:50（北京时间）。

## 研究结论与参数含义

跨10种语言的自然会话研究发现，人们倾向减少轮次间的空白和重叠，轮替间隔的分布峰值约在0–200毫秒；这研究的是人类自然接话，不能直接作为机器人的打断阈值。[Stivers等，2009](https://pmc.ncbi.nlm.nih.gov/articles/PMC2705608/)

综述指出，人类约200毫秒的轮替间隔比语言生成时间短，提示人们会在听话时提前预测话语结束。这支持结合接续与语义，而不是把固定静默时间视为已经说完。[Levinson与Torreira，2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4464110/)

近期语音对话模型研究也区分声音活动与轮次结束：单纯VAD难以区分话中停顿和真正说完；自然轮替还需处理插话、附和及语义连贯。[Arora等，2025](https://arxiv.org/abs/2510.02066)

对本项目的判断：不存在上述研究支持的统一“最适合插话的12秒”。12秒是用户选择的工程聚合上限，20字是信息积累的提前触发条件；二者都不证明对方说完，也不命令机器人开始讲话。是否回应或打断仍由相应判断流程决定。

## 当前聚合规则

- 无有效文字时等待输入，不启动或延长聚合计时。空白、仅标点的转写不创建待处理批次。
- 首个有效的ASR完成片段启动本批累计时间；不是从程序启动时计时，也不是从无文字的空闲期计时。ASR自身耗时不包含在此12秒内。
- 累计达到12秒，或已完成片段累计达到20个文字/数字字符，任一条件满足就进入判断。空白、标点不计，英文和数字按字符计；原话保留完整，不截成20字。
- 正常停顿1秒可提前收尾；明显未完句沿用至少4秒的停顿保护，连续有效转写会更新最后活动时间。字符或时间上限仍可触发分批，程序将其标为尚未观察到足够停顿。
- 本批提交后重新累计时间和字数；长停顿后的新输入属于新批。即使上一次处理造成排队，也根据收到转写时记录的间隔保留批次边界，不把空闲时间计入新批。
- ASR临时结果只更新活动时间，不按每次修订重复累计字数。明确停止沿用程序快捷判断，不等待一般聚合条件，也不额外请求模型决定“停止”这个规则。

聚合判断、候选准备、JEV请求和主认知分别有自己的耗时；12秒只约束收集阶段，不能声称整个回应一定在12秒内完成。使用文字活动时间而非原始音频VAD判断停顿，仍会受ASR输出节奏影响；没有新增声学或语义轮替模型。

## 片场和人物肖像

单条JEV作为兼容入口时，也接收聚合后的原话，不必每个完成片段都请求一次模型。

单条程序不发送JEV片场；以当时主认知片场、实际播放和近期未整理接续判断交往，提供输入截止时间前的主片场块（最多8块、合计2000字符，超预算整块省略）。已有人物文字肖像从主认知加载后的进程缓存复用，优先已有L3简短档；缺有效L3时复用已有短摘要，或对已有文字按句节选并注明边界，不新增浓缩调用：最多4人、每人200字符，缓存64条，并按主体与输入截止时间隔离；没有材料时不临时调用记忆后端或模型补取，不附人物照片。

肖像仅帮助理解交往，不证明当前声音身份；旧偏好不代替本轮意图。片场中的想法、准备说与实际播出分开。单条请求通过delivery.collection提供本批触发原因、字数与收尾状态，空状态不补造成已经说完；观察到停顿也不保证语义完整。批量JEV的任务、字段及路由保持原有分工；这些额外片场与肖像只给单条兼容模型分支，不额外重复发送给正常批量入口。

## 配置

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| JSHI_VOICE_INPUT_MAX_BATCH_MS | 12000 | 本批收集时间上限 |
| JSHI_VOICE_INPUT_BATCH_CHARS | 20 | 有效字符提前触发，0关闭此条件 |
| JSHI_VOICE_INPUT_PAUSE_MS | 1000 | 正常停顿收尾；未完句至少4秒 |

现有环境配置如显式指定其他值，仍以配置为准；修改配置需重启服务。程序与组包说明对应[P10-70](提示词/P10-70.0-单条JEV.md)、[P10-30](提示词/P10-30.0-第一次JEV.md)。
