# say hello · 主动思考

最近更新时间：2026-10-13 14:01（北京时间）。

原称“闲时刺激／闲时试验”。现在统一称为“say hello · 主动思考”：没有对方新发言时，由程序触发匠石主动启动一轮认知，结合当前材料决定是否开口、动作、等待或对内处理，不固定说hello，也不强制寒暄。这不是单独的自省调用。

与视觉事件区分：有效视觉变化是新的外部观察，进入视觉信封 → JEV → 主认知；say hello是在没有新发言时由计时触发的主动认知，两种来源不能互相冒充。目前say hello定时入口位于文字对话壳，语音网页尚未接入同一计时器。

默认无输入180秒触发，最多2轮；触发后重新计时，达到轮数上限后停止。模型可以选择不说话，不能把时间流过写成对方新说了一句话。当前文字壳在未切换对象时假定原对象仍在场，这是假定，不是视觉在场证据。

现有配置项保持兼容：`JSHI_IDLE_SECONDS`控制间隔，`JSHI_IDLE_MAX_ROUNDS`控制本次会话触发上限，`JSHI_IDLE_DISABLE=true`关闭。内部`idle`刺激类型、历史事件名称及提示词输入文字保留，不迁移旧记录。

阿丘是为这类触发补充判断说明的人格，底本与写场复用斯密斯；触发器不限于阿丘。各人格仍使用自己的完整认知提示词，不另外增加“say hello提示词”。

程序入口：[IdleTrial与handle_idle](../src/jshi/app/talk_session.py)。本次只修改显示名称和解释，并修正结束提示按实际配置的轮数显示；未改变认知提示词或触发条件。
