# 用 iPhone 连接匠石

iPhone 为桌面交谈页提供麦克风和摄像头。文字、转写、对话、播报、调试和识别服务设置都在原桌面页面使用。接入手机后，“来源”可以选择本机或在线的 iPhone。

## 连接

1. iPhone 和主机连同一 Wi-Fi，确认主机原有语音入口能正常识别和播报。使用当前主体、数据目录和语音配置启动服务。已在使用该数据目录的匠石服务，应先正常退出，再用新参数启动同一个实例。
2. 给原来的 `voice` 或 `vision` 命令追加 `--phone 主机的局域网IP`。例如，主机 Wi-Fi 地址为 `192.168.1.23`、主体为 `stone` 时：

   ```sh
   jshi voice stone --phone 192.168.1.23
   ```

   主机地址可在 Mac 的“系统设置 → Wi-Fi → 详细信息 → TCP/IP”查看。启用手机后，主机也会加载视觉服务，请在已有 Python 环境中安装项目的 `vision` 可选依赖。
3. 首次启动时，程序使用 OpenSSL 生成当前 IP 的证书，终端会打印 `iphone-ca.cer` 的位置。把这个**公开证书**隔空投送到自己的 iPhone，按系统提示安装描述文件。然后在“设置 → 通用 → 关于本机 → 证书信任设置”启用对“JShi Phone Local CA”的完全信任。私钥 `server.key` 留在主机。使用已有受信任的证书时，可传入 `--phone-cert 证书.pem --phone-key 私钥.pem`，证书须包含连接 IP 的 SAN。
4. Safari 打开终端打印的 HTTPS 地址，输入八位配对码并允许摄像头。再次打开已配对的页面时点“启用手机设备”。看到“已连接 · 待采集”后，可以先查看完整取景，再到桌面交谈页的“来源”里选这部 iPhone。
5. 像平常一样在桌面点“开始对话”或“开始视频”。首次采音时在手机允许麦克风。结束对话后，手机回到待采集。主机重启后需重新配对，服务证书可继续使用。

桌面交谈链接支持 `source=<设备 ID>`，可直接打开选中该 iPhone 的页面。设备 ID 来自桌面的 `GET /api/capture-sources`。打开链接后仍需点“开始对话”或“开始视频”。手机离线时，页面显示该来源未连接。

从 Model Desk 选择手机打开时，交谈页会等待 iPhone 上线。只有一部在线时自动选中，多部在线时由你选择。选定的手机断开后，页面保留该选择。工作台选择电脑时，交谈页直接使用本机。

默认桌面端口为 8765，手机端口为 8766。Model Desk 启动的实例请使用工作台显示的地址。手机端口可通过 `--phone-port` 调整。主机局域网 IP 改变后，用新 IP 启动并信任新证书。

## 操作

- **来源与声音**。先选来源，随后由桌面按钮开启采集。手机待机时可以继续使用本机。手机麦克风按钮控制静音。回复从桌面播放，保留原来的打断和播放回执。离线的 iPhone 在列表里显示为不可选。正在用的手机掉线后，本次采集结束，可重新连接或在桌面选择本机。
- **桌面播报回声**。选用手机时，匠石用交谈页实际播放的声音抵消手机麦克风收到的播报回声，再进行识别和打断判断。Mac 其他应用的外放声仍可能被手机拾取。
- **取景**。手机预览按镜头原始宽高比完整显示，横竖屏均可。底部是麦克风、摄像头和翻转镜头。待机时画面仅在手机显示。桌面开启视频后，已授权的手机镜头同时提供实时预览及识别用的采样图。
- **遮蔽与清晰度**。在“设置”中选择分辨率、识别采样间隔或“画遮蔽区”。编辑会暂停桌面传图和实时预览，确认后点“开始传画面”。更换镜头、画面方向或分辨率后也需确认。识别采样默认每两秒一张，主机的 `JSHI_VISION_SAMPLE_SECONDS` 决定最短间隔。
- **连接与延迟**。声音按 20 毫秒发送 PCM，局域网实时预览通过 WebRTC 传送遮蔽后的画面。预览协商不可用时，桌面显示最近的采样图。设置中可查看手机到主机的一次往返时间。锁屏或切到后台会释放设备，返回时点“启用手机设备”。

## 设备接口

| 请求 | 用途 |
| --- | --- |
| `POST /pair` | 同源提交八位配对码，设置 Secure、HttpOnly Cookie。 |
| `GET /api/device` | 配对状态、主机时间和最短采样间隔。 |
| `WSS /device-link` | 手机上线后收到 `available`。桌面开启对话后，手机收到 `start` 和本次令牌，回复 `started` 后发送 16 kHz 单声道 16 位小端 PCM。视频控制和局域网预览协商也走此连接。收到 `standby` 后停止上传。 |
| `POST /api/device/frame` | 提交遮蔽后的 JPEG，携带 `X-Device-Stream`、`X-Device-Camera`、`X-Device-Lens`、采集时间与时钟校准头。会话或视频开启周期失效时返回 409。 |

主机端的来源选择与归属规则见[实时采集源](实时采集源.md)。
