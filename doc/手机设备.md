# 用 iPhone 连接匠石

iPhone 提供麦克风、摄像头和扬声器。用 Safari 打开手机页面后，可以与匠石交谈，并把选定的画面交给主机。语音转写、视觉分析和信封组装沿用主机当前配置。

## 连接

1. iPhone 和主机连同一 Wi-Fi，确认主机原有语音入口能正常识别和播报。使用当前主体、数据目录和语音配置启动服务。已在使用该数据目录的匠石服务，应先正常退出，再用新参数启动同一个实例。
2. 给原来的 `voice` 或 `vision` 命令追加 `--phone 主机的局域网IP`。例如，主机 Wi-Fi 地址为 `192.168.1.23`、主体为 `stone` 时：

   ```sh
   jshi voice stone --phone 192.168.1.23
   ```

   主机地址可在 Mac 的“系统设置 → Wi-Fi → 详细信息 → TCP/IP”查看。启用手机后，主机也会加载视觉服务，请在已有 Python 环境中安装项目的 `vision` 可选依赖。
3. 首次启动时，程序使用 OpenSSL 生成当前 IP 的证书，终端会打印 `iphone-ca.cer` 的位置。把这个**公开证书**隔空投送到自己的 iPhone，按系统提示安装描述文件。然后在“设置 → 通用 → 关于本机 → 证书信任设置”启用对“JShi Phone Local CA”的完全信任。私钥 `server.key` 留在主机。使用已有受信任的证书时，可传入 `--phone-cert 证书.pem --phone-key 私钥.pem`，证书须包含连接 IP 的 SAN。
4. Safari 打开终端打印的 HTTPS 地址，默认端口为 `8766`。输入终端显示的八位配对码，点“连接匠石”并允许麦克风。可以用 Safari 的分享菜单将页面添加到主屏幕。主机每次重启后重新配对。

桌面入口仍使用 `http://127.0.0.1:8765`。手机和桌面共用一套识别、播报和会话资源，同一时间由一台设备提供实时音画。要换设备，先断开当前连接。手机静音、关摄像头或仅预览时，电脑仍需等手机断开才能接手。来源标识、切换及新设备接入见[实时采集源](实时采集源.md)。手机端口可用 `--phone-port` 调整。主机局域网 IP 改变后，用新 IP 启动并信任新证书。自动签发的服务证书有效期为一年，需要换证时先退出服务，将该 IP 的证书目录移走并重新启动。

## 操作

- **声音**。连上后即可听说。点“麦克风静音”仍可听回复，点“停止播报”会立即停止本地播放并通知主机。设备使用 iOS 浏览器提供的回声消除，插话沿用主机已有的停止和接续判断。
- **画面**。点“打开摄像头”进入仅预览状态。可以切换前后镜头，点“画遮蔽区”拖出一个或多个矩形，然后点“开始传画面”。每帧 JPEG 都从已遮蔽的预览画布编码。编辑、撤销、换镜头、旋转导致画幅改变或更改分辨率时，须重新确认传送。已送达的旧画面保留原样。
- **清晰度与采样**。发送分辨率按长边选 640、1280 或 1920 像素，并受镜头实际分辨率限制。默认每两秒采一张。主机的 `JSHI_VISION_SAMPLE_SECONDS` 设定允许的最短间隔，例如设为 `0.5` 并重启后可在手机选择每半秒一张。图像单独上传，上一张还在传或声音已经积压时跳过本次画面。
- **失联与后台**。页面在前台遇到网络断开会尝试重连，保留静音选择，摄像头须重新打开。锁屏或切到后台时页面主动释放采集，回来后点“连接匠石”。断开连接会释放麦克风、镜头和播放器。
- **延迟**。页面右上角显示手机到设备接口的一次 HTTP 往返时间。上行音频每 20 毫秒发一个 PCM 包。回包间隔、网络往返和“说完到听见回复”是不同的指标。主机现有的语音计时及播放回执可用来查识别、判断、合成和播出各段耗时。

## 设备接口

设备专用 HTTPS 监听与桌面服务共进程，设备端口只提供手机静态页面和以下路由。主机生成配对 Cookie，会话就绪时另发一个仅限本次连接的画面令牌。设备来源随配对区分，镜头与语音会话保留关联，设备标记不参与人物身份判定。

| 请求 | 用途 |
| --- | --- |
| `GET /api/device` | 返回配对状态、服务器时间（Unix 秒）、主机最短采样间隔及语音占用情况。 |
| `POST /pair` | 正文为八位配对码。同源校验通过后设置 Secure、HttpOnly Cookie。 |
| `WSS /voice` | 使用主机配置的 ASR 和 TTS。收到 `ready` 后上传 16 kHz 单声道有符号 16 位小端 PCM 二进制。下行按回复和语段流式传音频，播放端执行暂停、接续及停止，并回报已开始或已播完的语段。 |
| `POST /api/device/frame` | 同源发送已遮蔽 JPEG。请求头包含 `X-Device-Stream`、`X-Device-Lens`（user 或 environment）、`X-Captured-At`（采集时间，Unix 秒）、`X-Clock-Offset` 和 `X-Clock-Uncertainty`（秒）。返回 202 表示进入视觉入口，409 表示会话失效，408 或 429 表示应跳过这张画面。 |
