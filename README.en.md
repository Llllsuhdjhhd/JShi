# JShi

JShi is an experimental subject-process framework for a long-lived AI companion. Its current project map is intentionally coarse; implementation details are documented as modules are worked on.

- [Project map](doc/项目脉络.md)
- [Documentation index](doc/README.md)
- [Module draftbox](doc/草稿箱/README.md)
- [Archived documents](doc/历史文档/README.md)

The code and its tests define current behavior. Legacy design documents are preserved under doc/历史文档 and may be outdated.

Requires Python 3.11 or newer. Install with python -m pip install -e ".[dev]", then run jshi --help. CLI configuration examples are in .env.example. Run the offline test suite with python -m pytest -q.

This project is experimental; interfaces and behavior may change. Some action, feedback, and governance implementations remain placeholders.
