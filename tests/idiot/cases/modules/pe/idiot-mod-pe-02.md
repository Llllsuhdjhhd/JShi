# idiot-mod-pe-02

- 模块：PE 个人内容（书本变迁）
- 人格：`myshkin-init-v1` → 叠加 `presets/transitions/` 中某一书本变迁包（材料齐后填具体文件名）
- 记忆集：变迁所依据的 pack（只作依据声明；写入人格仍来自变迁包，不是程序应对）
- 报告要求：变迁前/后 `personal` 全文；新增/结束条目表；依据路径

## 步骤

1. 装载 init，列出 personal（基线）
2. 仅按变迁包写入书本条目
3. 再列出 personal
4. 确认未运行 experience，或运行后做污染检查且人格未因生成而变

## 期望

- 仅出现变迁包声明的增量
- 可追溯 from_version → to_version

## 失败

- 出现变迁包未写明的条目
- 用程序应对“总结”出的价值被写入
