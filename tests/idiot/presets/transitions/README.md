# 人格变迁包（书本驱动）

此处只放**依据书中已发生对白**整理的人格变动，供后续测试点叠加到 `myshkin-init-v*` 之上。

## 命名

`after-{锚点}-v{n}.md` + 可选同名 `.json`

例：`after-T1-train-v1.md` = 火车场次对白之后、由书本落实的条目增量。

## 禁止

- 根据程序 `experience` 输出归纳新价值/承诺再写入。
- 写入尚未发生的后文关系。

## 文件应写明

- `from_version` / `to_version`
- 依据的 `corpus/` 或 `packs/` 路径
- 新增、结束的个人内容与未完成现实列表
